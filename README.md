# Web Technologies Practical Repository

A structured collection of practical web development exercises covering the fundamentals of the World Wide Web, networking, HTML, HTML5, and XML.

This repository is designed for learning and documentation-first practice. It organizes core theory, examples, and browser-based labs in a way that is easy to browse and understand.

## What is included

- WWW and networking basics
- HTML and HTML5 practicals
- Comparison notes and concept summaries
- Browser-ready examples for learning and revision

## Why it is useful

It gives learners a clean reference point for understanding how web technologies work together and how foundational topics are applied in real web projects.

## How to use it

Open the practical files in a browser or use a local live preview extension in VS Code.

```bash
git clone https://github.com/yashpnd4/web-technology-.git
cd web-technology-
```

Then open the `main` folder or `main.html` entry page to explore the exercises.

## Topics covered

- Internet and WWW basics
- HTTP and DNS fundamentals
- URL structure and web architecture
- HTML structure and semantics
- Lists, tables, forms, and media
- XML concepts and markup structure
