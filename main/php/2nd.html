Introduction and Basic Syntax of PHP

1. Basic PHP Syntax

PHP statements are commonly written between <?php and ?> tags. A semicolon ends most PHP statements. 

<?php
echo "Hello, World!";
?>
  • <?php starts a PHP code block.
  • ?> closes a PHP code block when needed.
  • echo outputs text or values.
  • A semicolon ends most statements.

2. PHP Comments

Comments explain code and are not executed as PHP statements.

// This is a single-line comment

# This is also a single-line comment

/*
This is a
multi-line comment.
*/

3. PHP Variables and Data Types

PHP variable names begin with a dollar sign ($). Variable names are case-sensitive. PHP is dynamically typed, so a variable can hold values of different types.

Common PHP data types include:

  • String: Text.
  • Integer: Whole number.
  • Float: Decimal number.
  • Boolean: true or false.
  • Array: Stores multiple values.
  • Object: Stores data and related behavior.
  • NULL: Represents no value.

4. PHP Output and Strings

The echo statement displays output. Single-quoted strings are mostly literal. Double-quoted strings can interpolate variables and interpret sequences such as \n. The dot (.) operator joins strings. 

<?php
$student = 'Mira';
$unit = 6;

echo "Student: $student\n";
echo 'Unit: ' . $unit . "\n";
?>

In this example, the dot operator joins the text with the value stored in the variable.

5. PHP Arrays

Arrays store multiple values. Two common array types are:

  • Indexed Array: Stores ordered values using numeric indexes.
  • Associative Array: Stores values using named keys.
<?php
$topics = ['PHP syntax', 'Strings', 'Frameworks'];

$marks = [
    'Mira' => 88,
    'Dev' => 76
];

echo $topics[0];
echo $marks['Mira'];
?>

6. Conditions and Loops

Conditions make decisions based on values. PHP uses if, elseif, and else statements. Loops repeat instructions. The foreach loop is commonly used to visit each item in an array. 

<?php
$marks = 88;

if ($marks >= 40) {
    echo 'Pass';
} else {
    echo 'Needs more practice';
}

$topics = ['PHP syntax', 'Strings', 'Frameworks'];

foreach ($topics as $topic) {
    echo $topic . PHP_EOL;
}
?>

7. PHP Functions

A function groups reusable behavior. It can receive parameters and return a result. Parameter and return types can make intended inputs and outputs clear. 

<?php
function resultLabel(int $marks): string
{
    if ($marks >= 40) {
        return 'Pass';
    }

    return 'Needs more practice';
}

echo resultLabel(88);
?>

8. Complete Example: Variables, Arrays, and Loops

<?php
declare(strict_types=1);

$student = 'Mira';
$unit = 6;
$passed = true;
$topics = ['PHP syntax', 'Strings', 'Frameworks'];
$marks = ['Mira' => 88, 'Dev' => 76];

echo "Student: $student\n";
echo 'Unit: ' . $unit . "\n";
echo 'Passed: ' . ($passed ? 'yes' : 'no') . "\n";

foreach ($topics as $index => $topic) {
    echo ($index + 1) . ". $topic\n";
}

foreach ($marks as $name => $score) {
    echo "$name scored $score\n";
}
?>

9. Important Points

  • PHP code is written between PHP tags.
  • Variable names begin with $ and are case-sensitive.
  • A semicolon ends most statements.
  • Use echo to display output.
  • Indexed arrays use numeric indexes; associative arrays use keys.
  • Conditions, loops, and functions control program logic.
