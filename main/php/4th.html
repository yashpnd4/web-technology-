Web Development Frameworks and MVC

1. What is a Web Development Framework?

A web framework is a reusable foundation for building applications. A PHP framework gives a project structure and provides components for common tasks such as routing requests, validating input, rendering templates, accessing databases, handling sessions, and testing.

Instead of rebuilding those features for every project, developers use the framework's conventions and libraries.

2. What is MVC?

MVC stands for Model, View, and Controller. It is a common pattern for separating responsibilities in an application.

Part Purpose
Model Represents or accesses application data and domain rules, such as a course or student record.
View Formats the response for the user, commonly with an HTML template populated with data.
Controller Receives a request, coordinates relevant work, and selects the response. A route may call a controller action.

MVC is a common organizational pattern, not a requirement that every framework or application uses exactly the same file layout. Separating responsibilities can make a project easier to test and maintain.

3. Common PHP Frameworks

Framework Overview Often Chosen For
Laravel Full-featured framework with expressive routing, Blade templates, ORM, migrations, and a broad ecosystem. Modern web applications and rapid development with integrated tools.
Symfony Modular framework and reusable components with strong configuration and long-term project capabilities. Large or complex applications that benefit from flexible components and explicit structure.
CodeIgniter Lightweight framework with a relatively small footprint and straightforward setup. Projects seeking a simpler framework with fewer built-in moving parts.

4. Example: Create a Laravel Project

The study guide uses Laravel as an example of a PHP web framework. Install Composer and a supported PHP version first. 

composer create-project laravel/laravel php-framework-demo
cd php-framework-demo
php artisan serve

The command creates a new Laravel project, changes to its directory, and starts the local development server.

5. Example Laravel Route

Replace the contents of routes/web.php in the generated project with this example: 

<?php

use Illuminate\Support\Facades\Route;

Route::get('/hello/{name}', function (string $name) {
    return view('hello', ['name' => $name]);
});

Visit the URL shown by Artisan, usually http://127.0.0.1:8000/hello/Asha. The route returns a response generated by the framework.

6. Example Blade View

Create resources/views/hello.blade.php with this template. Blade's double-brace output syntax escapes HTML by default. 

<!doctype html>
<html lang="en">
<head>
    <meta charset="utf-8">
    <title>Framework Greeting</title>
</head>
<body>
    <h1>Hello, {{ $name }}!</h1>
    <p>This page is returned through a Laravel route and view.</p>
</body>
</html>

7. When to Use a Framework

  • Choose a framework when the application needs routing, database access, authentication, validation, and ongoing maintenance.
  • For a very small script or learning exercise, plain PHP may be enough.
  • Understand PHP fundamentals before adding framework abstractions.
  • Use documented security features and keep dependencies updated.
  • A framework does not automatically make insecure code safe.

Composer is PHP's dependency manager. The Laravel example requires a working PHP and Composer installation and internet access to download project dependencies. It cannot execute just by opening this study-guide HTML file.

8. Important Points

  • A web framework provides reusable structure and components.
  • MVC separates Model, View, and Controller responsibilities.
  • Laravel, Symfony, and CodeIgniter are common PHP frameworks.
  • Composer is PHP's dependency manager.
  • Learn PHP fundamentals before using a framework.
