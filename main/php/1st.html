Introduction to Server-Side Scripting

1. What is Server-Side Scripting?

Server-side scripting is a process in which a script runs on a web server instead of the visitor's browser. The server can process requests, read or update data, apply application rules, and send a response such as HTML or JSON.

2. What is PHP?

PHP originally meant Personal Home Page and is now commonly expanded as PHP: Hypertext Preprocessor. It is an open-source scripting language widely used for web development. PHP code can be embedded in HTML and is executed by a PHP runtime on the server.

3. How Client and Server Work

Browser / Client Web Server + PHP
Sends an HTTP request, such as requesting a page or submitting a form. It receives the response and displays it. Receives the request, executes the PHP script, and creates a response. PHP source code is not sent to the browser.

A server-side application may also read or write data in a database or files, subject to authorization and validation rules.

4. Request and Response Flow

  1. A browser requests a PHP route, for example http://localhost:8000/hello.php.
  2. The web server passes the request to the PHP interpreter.
  3. The PHP script runs on the server and may combine data with an HTML template.
  4. The server sends the generated response to the browser, and the browser displays the result.

5. First PHP Server-Side Script

Save the following code as hello.php. It creates an HTML response using PHP. 

<?php
$name = 'Asha';
$hour = (int) date('G');
$greeting = $hour < 12 ? 'Good morning' : 'Hello';
?>
<!doctype html>
<html lang="en">
<head>
    <meta charset="utf-8">
    <title>PHP Greeting</title>
</head>
<body>
    <h1><?= htmlspecialchars($greeting . ', ' . $name, ENT_QUOTES, 'UTF-8') ?></h1>
    <p>This response was generated by PHP on the server.</p>
</body>
</html>

The opening tag <?php starts PHP code. The short echo tag <?= ... ?> outputs a value. The browser receives the generated HTML, not the PHP statements that created it.

htmlspecialchars() encodes text for safe insertion into HTML.

6. How to Run a PHP File

Opening a .php file by double-clicking it with a file:// URL does not execute PHP.

Start PHP's local development server:

php -S localhost:8000

Then open this address in a browser:

http://localhost:8000/hello.php

Command-line alternative:

php hello.php

The command-line alternative prints the generated output in the terminal. Never expose database passwords or private PHP source code in a public web directory.

7. Important Points

  • Server-side scripts run on a web server.
  • PHP code is executed by a PHP runtime.
  • The browser receives the generated response, not the PHP source code.
  • PHP can generate HTML or JSON.
  • A PHP file must be run through PHP or a web server configured with PHP.
