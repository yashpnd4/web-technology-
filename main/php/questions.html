PHP Questions and Answers

Basic PHP Questions and Answers

These 15 questions cover Unit 6: server-side scripting, PHP syntax, variables, data types, arrays, conditions, loops, functions, form handling, strings, regular expressions, frameworks, and MVC.

1. What is server-side scripting?

Answer: Server-side scripting is a process in which a script runs on a web server instead of the visitor's browser. The server can process requests, read or update data, apply application rules, and send a response such as HTML or JSON.

2. What is PHP? What does PHP stand for?

Answer: PHP originally meant Personal Home Page and is now commonly expanded as PHP: Hypertext Preprocessor. It is an open-source scripting language widely used for web development. PHP code can be embedded in HTML and is executed by a PHP runtime on the server.

3. Explain the PHP request and response flow.

Answer:

  1. A browser requests a PHP route or file.
  2. The web server passes the request to the PHP interpreter.
  3. The PHP script runs on the server and may combine data with an HTML template.
  4. The server sends the generated response to the browser.

The browser receives the generated response, not the PHP source code.

4. What are the basic PHP syntax rules?

Answer:

  • PHP code is commonly written between <?php and ?>.
  • A semicolon ends most statements.
  • Variable names begin with the dollar sign ($).
  • Variable names are case-sensitive.
  • Comments can be written using // or /* ... */.
<?php
echo "Hello, World!";
?>

5. What are PHP variables and data types?

Answer: A variable stores data. PHP variable names begin with $. Common data types include string, integer, float, Boolean, array, object, and NULL. 

<?php
$student = 'Mira';
$unit = 6;
$passed = true;
$price = 45.50;
?>

6. What is the difference between single-quoted and double-quoted strings in PHP?

Answer: Single-quoted strings are mostly literal. Double-quoted strings can interpolate variables and interpret sequences such as the newline sequence \n. 

<?php
$name = 'Mira';

echo 'Student: ' . $name;
echo "Student: $name";
?>

7. What are indexed and associative arrays?

Answer:

  • Indexed Array: Stores ordered values using numeric indexes.
  • Associative Array: Stores values using named keys.
<?php
$topics = ['PHP syntax', 'Strings', 'Frameworks'];

$marks = [
    'Mira' => 88,
    'Dev' => 76
];

echo $topics[0];
echo $marks['Mira'];
?>

8. What are conditions and loops in PHP?

Answer: Conditions make decisions based on values. PHP uses if, elseif, and else. Loops repeat instructions. Common loops include for, while, and foreach. 

<?php
$marks = 88;

if ($marks >= 40) {
    echo 'Pass';
} else {
    echo 'Needs more practice';
}

$topics = ['PHP', 'Strings'];

foreach ($topics as $topic) {
    echo $topic;
}
?>

9. What is a function in PHP?

Answer: A function is a reusable block of code that performs a task. It can receive parameters and return a value. PHP also supports parameter and return types. 

<?php
function resultLabel(int $marks): string
{
    if ($marks >= 40) {
        return 'Pass';
    }

    return 'Needs more practice';
}

echo resultLabel(88);
?>

10. How is form data handled safely in PHP?

Answer: PHP can check the request method and read submitted values from the $_POST array. The application should trim and validate input, then encode output before inserting it into HTML.

  • $_SERVER['REQUEST_METHOD'] checks the request method.
  • $_POST reads values submitted using POST.
  • trim() removes whitespace at the beginning and end.
  • htmlspecialchars() encodes text for safe HTML output.

Client input is untrusted and must be validated.

11. What are common PHP string functions?

Answer:

  • trim() - Removes whitespace at the beginning and end.
  • strlen() - Counts string length in bytes.
  • mb_strlen() - Counts characters in Unicode text when mbstring is enabled.
  • str_replace() - Replaces literal text.

12. What is a regular expression? What is PCRE?

Answer: A regular expression (regex) describes a pattern in text. PHP's preg_* functions use PCRE, which stands for Perl Compatible Regular Expressions. It can find, extract, or replace matching text.

13. Explain preg_match() and preg_replace().

Answer:

  • preg_match() checks whether a pattern matches a string. It returns 1 for a match, 0 for no match, or false on error.
  • preg_replace() replaces text that matches a pattern. It returns modified text or null on error.
<?php
$email = 'learner@example.edu';
$pattern = '/^[A-Z0-9._%+-]+@[A-Z0-9.-]+\.[A-Z]{2,}$/i';

$match = preg_match($pattern, $email);
?>

14. What is a PHP framework? Name some common PHP frameworks.

Answer: A PHP framework is a reusable foundation for building web applications. It provides structure and components for routing, validation, templates, database access, sessions, and testing.

  • Laravel: Full-featured framework with routing, Blade templates, ORM, migrations, and a broad ecosystem.
  • Symfony: Modular framework with reusable components and flexible configuration.
  • CodeIgniter: Lightweight framework with a relatively small footprint and straightforward setup.

15. What is MVC? Explain Model, View, and Controller.

Answer: MVC stands for Model, View, and Controller. It is a common way to separate application responsibilities.

  • Model: Represents or accesses application data and domain rules.
  • View: Formats the response for the user, commonly using an HTML template.
  • Controller: Receives a request, coordinates the work, and selects the response.

MVC can make an application easier to test and maintain.
