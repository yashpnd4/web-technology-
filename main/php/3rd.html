String Processing and Regular Expressions

1. What is a String?

A string is a sequence of text characters. PHP provides functions to inspect, trim, split, search, replace, and format strings.

2. Common PHP String Functions

Task PHP Function Purpose
Remove whitespace at the ends trim() Removes whitespace from the beginning and end of a string.
Count characters strlen() / mb_strlen() Counts string length. Use mb_strlen() for Unicode text when the mbstring extension is enabled.
Replace literal text str_replace() Replaces matching text with another value.
Find a regular-expression match preg_match() Checks whether a pattern matches a string.
Replace a regular-expression match preg_replace() Replaces text that matches a pattern.

3. Using trim() and str_replace()

The trim() function removes whitespace at the beginning and end of a string. The str_replace() function replaces literal text. 

<?php
$raw = '      Contact: learner@example.edu       ';

$clean = trim($raw);

$normalized = str_replace('Contact:', 'Email:', $clean);

echo $normalized . PHP_EOL;
?>

Output:

Email: learner@example.edu

4. What is a Regular Expression?

A regular expression (regex) describes a pattern in text. PHP's preg_* functions use PCRE, which stands for Perl Compatible Regular Expressions. Regular expressions can find patterns, extract matches, or replace matched text.

5. Common Regex Symbols

Symbol Meaning
/.../Slash delimiters used around a regular-expression pattern.
iCase-insensitive matching modifier.
^Anchors a match to the start of the string.
$Anchors a match to the end of the string.
[A-Z]Matches an uppercase letter from A to Z.
+Matches one or more of the preceding item.
\.Matches a literal dot.
\DMatches any non-digit character.

6. Using preg_match()

The preg_match() function searches a string for a regular-expression pattern. It returns 1 for a match, 0 when there is no match, or false if an error occurs. 

<?php
$email = 'learner@example.edu';

$pattern = '/^[A-Z0-9._%+-]+@[A-Z0-9.-]+\.[A-Z]{2,}$/i';

$match = preg_match($pattern, $email);

if ($match === false) {
    throw new RuntimeException('The regular expression could not be processed.');
}

echo ($match === 1)
    ? 'Email-like format found'
    : 'No email-like format found';
?>

This pattern checks a common email-like shape. It does not prove that the address exists or can receive email.

7. Using preg_replace()

The preg_replace() function replaces text that matches a regular expression. It can be used to remove unwanted characters from a string. 

<?php
$phone = '(555) 123-4567';

$digits = preg_replace('/\D+/', '', $phone);

if ($digits === null) {
    throw new RuntimeException('The replacement pattern could not be processed.');
}

echo "Digits only: $digits";
?>

Output:

Digits only: 5551234567

8. Complete String and Regex Example

<?php
$raw = '      Contact: learner@example.edu       ';
$clean = trim($raw);
$normalized = str_replace('Contact:', 'Email:', $clean);

echo $normalized . PHP_EOL;

$email = 'learner@example.edu';
$pattern = '/^[A-Z0-9._%+-]+@[A-Z0-9.-]+\.[A-Z]{2,}$/i';
$match = preg_match($pattern, $email);

if ($match === false) {
    throw new RuntimeException('Regex error');
}

echo ($match === 1 ? 'Email-like format found' : 'No match') . PHP_EOL;

$phone = '(555) 123-4567';
$digits = preg_replace('/\D+/', '', $phone);

if ($digits === null) {
    throw new RuntimeException('Regex replacement error');
}

echo "Digits only: $digits" . PHP_EOL;
?>

9. Choosing the Right Tool

  • Prefer simple string functions for literal replacements and searches.
  • Use regular expressions when the pattern itself varies.
  • Use filter_var($email, FILTER_VALIDATE_EMAIL) for PHP email-format validation.
  • Confirm email ownership when needed.
  • Regex checks do not replace server-side validation, output encoding, or security controls.

10. Important Points

  • trim() removes whitespace at the start and end of a string.
  • strlen() and mb_strlen() can count string length.
  • str_replace() replaces literal text.
  • preg_match() checks whether a pattern matches.
  • preg_replace() replaces text that matches a pattern.
  • Regex uses delimiters, anchors, character classes, and modifiers.
