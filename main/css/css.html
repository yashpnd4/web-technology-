Cascading Style Sheets (CSS)

Styling and Designing Web Pages

Introduction

CSS stands for Cascading Style Sheets.

CSS is used to control the appearance of HTML pages. It changes the colors, fonts, text size, spacing, borders, backgrounds, and position of HTML elements. HTML creates the structure of a webpage, while CSS controls how that structure looks.

Why CSS is Used

  • Separate Design: CSS keeps the design separate from the HTML content.
  • Reuse: One stylesheet can be used on many HTML pages.
  • Easy Updates: Changing one CSS rule can update the appearance of many pages.
  • Different Screens: CSS can help pages adjust to mobiles, tablets, and computers.
