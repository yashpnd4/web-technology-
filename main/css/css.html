Introduction

HTML describes the meaning and structure of content. CSS controls how that content is presented, including its colors, typography, spacing, borders, and layout.

HTML handles structure

Meaningful headings, paragraphs, lists, links, images, and forms belong in HTML.

CSS handles presentation

Visual rules such as color, font, spacing, borders, and page layout belong in CSS.

Three Ways to Add CSS

MethodWhere it goesBest suited for
External stylesheetA .css file linked from the HTML <head>Shared site-wide styles and maintainable projects.
Internal stylesheetA <style> element in the document <head>Styles used by one standalone page.
Inline styleThe element's style attributeA one-off demonstration; avoid repeated styling.
Study tip: Learn the purpose of each CSS property, then practise changing its value and observing the result in a browser.
