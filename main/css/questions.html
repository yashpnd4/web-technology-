Basic CSS Questions and Answers

These questions cover the basic concepts of CSS Unit 3, including CSS syntax, selectors, colors, backgrounds, text, borders, the box model, positioning, and modern CSS features.

1. What is CSS?

Answer: CSS stands for Cascading Style Sheets. It is used to control the appearance and layout of HTML webpages. CSS can change colors, fonts, text size, spacing, borders, backgrounds, and the position of HTML elements.

2. Why is CSS needed?

Answer: CSS is needed for the following reasons:

  • It separates webpage content from its design.
  • It allows the same design to be reused on multiple pages.
  • It makes website design easier to maintain and update.
  • It helps webpages adjust to different screen sizes.
  • It reduces repeated styling code.

3. What are the three ways to add CSS to HTML?

Answer: There are three ways to add CSS:

  1. Inline CSS: Written inside the style attribute of an HTML element.
  2. Internal CSS: Written inside the style tag in the head section.
  3. External CSS: Written in a separate .css file and connected using the link tag.

Example of inline CSS:

<p style="color: red;">This is a red paragraph.</p>

4. What is CSS syntax?

Answer: CSS syntax is the structure used to write CSS rules. A CSS rule contains a selector and a declaration block. The declaration block contains properties and values. 

selector {
    property: value;
}

Example:

p {
    color: blue;
    font-size: 20px;
}

5. What are CSS selectors? Name some common types.

Answer: CSS selectors are used to select HTML elements that we want to style. Common types include:

  • Element selector: Selects elements by tag name, such as p.
  • Class selector: Selects elements by class name and starts with a dot, such as .notice.
  • ID selector: Selects an element by ID and starts with a hash, such as #heading.
  • Universal selector: Selects all elements and uses *.
  • Group selector: Applies the same rule to multiple selectors, such as h1, h2.
  • Pseudo-class selector: Selects an element in a state, such as a:hover.

6. What are CSS units? Give examples.

Answer: CSS units are used to set sizes, spacing, and dimensions. Common units are:

  • px: CSS pixel.
  • em: Relative to the element's font size, with font-size based on the parent.
  • rem: Relative to the root element's font size.
  • %: A percentage based on the property and its context.
  • vw: One percent of the viewport width.
  • vh: One percent of the viewport height.

7. What is the difference between cascade and inheritance?

Answer: The cascade decides which CSS rule is used when more than one rule applies to an element. It considers importance and origin, selector specificity, and source order.

Inheritance means some properties, such as color and font-family, can pass from a parent element to its child elements. Properties such as margin, padding, and border do not normally inherit.

8. What are RGB, RGBA, HSL, and HSLA colors?

Answer:

  • RGB: Uses Red, Green, and Blue values. Each value normally ranges from 0 to 255.
  • RGBA: RGB with an additional Alpha value to control transparency.
  • HSL: Uses Hue, Saturation, and Lightness.
  • HSLA: HSL with an additional Alpha value for transparency.

Examples:

color: rgb(255, 0, 0);
color: rgba(255, 0, 0, 0.5);
color: hsl(9, 100%, 64%);
color: hsla(9, 100%, 64%, 0.5);

9. What are CSS background properties?

Answer: Background properties are used to control the background of an HTML element.

  • background-color - Sets the background color.
  • background-image - Sets a background image or gradient.
  • background-repeat - Controls image repeating.
  • background-position - Sets the image position.
  • background-size - Controls the image size.
  • background-attachment - Controls how the background moves while scrolling.

10. Name some CSS font and text properties.

Answer: Common CSS font and text properties are:

  • font-family - Changes the type of font.
  • font-size - Changes the size of text.
  • font-weight - Changes the thickness of text.
  • text-align - Aligns text.
  • line-height - Sets space between lines.
  • text-decoration - Adds underline, overline, or line-through.
  • text-transform - Changes the visual letter case.

11. What is the CSS border property?

Answer: The border property is used to create a line around an HTML element. It can set border width, style, and color together. 

p {
    border: 2px solid red;
}

Common border styles include solid, dotted, dashed, double, and none.

12. What is the CSS box model?

Answer: The CSS box model describes the space around an HTML element. It contains four parts:

  1. Content: The text, image, or other content inside the element.
  2. Padding: The space between content and border.
  3. Border: The line around the padding and content.
  4. Margin: The space outside the border.

13. What is the difference between content-box and border-box?

Answer: In content-box, the declared width applies only to the content. Padding and border are added to the total width. In border-box, the declared width includes content, padding, and border.

14. What are the five types of CSS positioning?

Answer: The five common position values are:

  • Static: The default position in normal document flow.
  • Relative: Moves from its normal position while keeping its original space.
  • Absolute: Is removed from normal flow and positioned relative to its nearest positioned ancestor.
  • Fixed: Is positioned relative to the viewport.
  • Sticky: Behaves like relative positioning until it reaches a scroll position, then sticks within its container.

15. What are Flexbox, CSS Grid, and Media Queries?

Answer:

  • Flexbox: A layout method used to arrange elements in one direction, in a row or a column.
  • CSS Grid: A layout method used to arrange elements in rows and columns.
  • Media Queries: Apply CSS rules when a condition is true, such as when the screen width is below a certain size. They help create responsive webpages.
