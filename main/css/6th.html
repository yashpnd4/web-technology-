CSS3 and Modern CSS Features

← Back to CSS Overview

1. Introduction to CSS3

CSS3 is a commonly used name for newer CSS features. Modern CSS is developed in different modules such as colors, selectors, grid, and media queries.

2. Rounded Corners

The border-radius property is used to make the corners of an element rounded. 

div {
    border: 2px solid blue;
    border-radius: 10px;
}

3. Box Shadow

The box-shadow property is used to add a shadow around an HTML element. 

div {
    box-shadow: 5px 5px 10px gray;
}

4. CSS Gradients

A gradient is a smooth change from one color to another. The linear-gradient() function is used to create a linear gradient. 

div {
    background: linear-gradient(red, yellow);
}

5. Transform and Transition

The transform property is used to move, rotate, or scale an element. The transition property makes a change happen smoothly over a period of time. 

div {
    transform: scale(1.1);
    transition: 0.5s;
}

6. Flexbox

Flexbox is a CSS layout method used to arrange elements in one direction, either in a row or a column. 

.container {
    display: flex;
    gap: 10px;
}

7. CSS Grid

CSS Grid is a layout method used to arrange elements in rows and columns. 

.container {
    display: grid;
    grid-template-columns: 1fr 1fr;
    gap: 10px;
}

8. Media Queries

Media queries are used to apply CSS rules depending on screen size or other device conditions. They help create responsive webpages. 

@media (max-width: 600px) {
    body {
        background-color: lightblue;
    }
}

9. Reduced Motion

Some users prefer fewer animations. CSS provides the prefers-reduced-motion media feature to reduce or remove motion effects for those users. 

@media (prefers-reduced-motion: reduce) {
    * {
        transition: none;
        transform: none;
    }
}

10. Important Points

  • border-radius creates rounded corners.
  • box-shadow adds a shadow.
  • linear-gradient() creates a color gradient.
  • transform changes the position, size, or rotation of an element.
  • transition makes property changes smooth.
  • Flexbox arranges items in one direction.
  • Grid arranges items in rows and columns.
  • Media queries help webpages adjust to screen sizes.
