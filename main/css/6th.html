1. CSS3 and Modern CSS

CSS is developed as a collection of modules, such as Color, Selectors, Grid, and Media Queries. "CSS3" is still commonly used as a classroom label for newer features, but there is no single all-encompassing CSS3 or CSS4 release. Individual modules evolve on their own timelines.

2. Choosing a Layout Method

  • Normal document flow: suitable for most text and block content.
  • Flexbox: useful for arranging items along one main direction, such as a row of navigation links.
  • Grid: useful when a layout needs rows and columns together, such as a group of cards.

Flexbox and Grid can be combined. Neither requires fixed pixel widths for every item.

Flexbox example

.flex-row {
    display: flex;
    gap: 12px;
    justify-content: space-between;
    align-items: center;
}

4. Responsive Layout with Media Queries

A media query applies rules only when a condition is true, such as a narrow viewport or a request to reduce motion. Choose breakpoints when the content needs them rather than targeting a particular phone model.

@media (max-width: 600px) {
    .feature-list {
        grid-template-columns: 1fr;
    }
}

Flexible tracks such as minmax() and auto-fit can adapt between breakpoints.

5. Respect Reduced-Motion Preferences

Some users prefer less animation. The prefers-reduced-motion media feature allows a page to reduce or remove motion effects for users who have enabled that preference.

@media (prefers-reduced-motion: reduce) {
    .motion-demo,
    .motion-demo:hover {
        transition: none;
        transform: none;
    }
}

6. Unit 3 Recap

  1. HTML supplies the structure; CSS controls its presentation.
  2. Selectors choose elements, declarations set values, and the cascade resolves competing rules.
  3. Inheritance, units, colors, text, borders, and the box model shape how content is displayed.
  4. Positioning, Flexbox, Grid, and media queries help arrange content across screen sizes.
  5. Modern CSS is modular and continues to evolve through individual specifications.
