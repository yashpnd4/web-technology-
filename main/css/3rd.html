CSS Colors and Backgrounds

← Back to CSS Overview

1. CSS Colors

CSS colors are used to change the text color and background color of HTML elements. Colors can be written using color names, HEX, RGB, RGBA, HSL, and HSLA values.

A. Color Name

We can use standard color names such as red, blue, green, black, and white.

h1 {
    color: red;
}

B. HEX Color

HEX colors use hexadecimal values. They normally contain a hash sign followed by six digits or letters.

p {
    color: #0000FF;
}

C. RGB Color

RGB stands for Red, Green, and Blue. Each value normally ranges from 0 to 255.

h1 {
    color: rgb(255, 0, 0);
}

Examples:

  • rgb(255, 0, 0) - Red
  • rgb(0, 255, 0) - Green
  • rgb(0, 0, 255) - Blue
  • rgb(0, 0, 0) - Black
  • rgb(255, 255, 255) - White

D. RGBA Color

RGBA stands for Red, Green, Blue, and Alpha. The alpha value controls transparency. It ranges from 0 (transparent) to 1 (fully opaque). 

p {
    color: rgba(255, 0, 0, 0.5);
}

E. HSL and HSLA Colors

HSL stands for Hue, Saturation, and Lightness. HSLA also includes an alpha value for transparency. 

h1 {
    color: hsl(9, 100%, 64%);
}

p {
    color: hsla(9, 100%, 64%, 0.5);
}

2. Background Color

The background-color property is used to set the background color of an HTML element. 

body {
    background-color: lightblue;
}

3. Background Image

The background-image property is used to set an image as the background of an element. 

body {
    background-image: url("image.jpg");
}

4. Background Properties

Property Use
background-colorSets the background color.
background-imageSets a background image or gradient.
background-repeatControls whether the background image repeats.
background-positionSets the starting position of the background image.
background-sizeControls the size of the background image.
background-attachmentControls how the background moves when the page is scrolled.

Example of Background Properties

body {
    background-color: lightblue;
    background-image: url("image.jpg");
    background-repeat: no-repeat;
    background-position: center;
    background-size: cover;
    background-attachment: fixed;
}

5. Important Points

  • Use color to change text color.
  • Use background-color to change background color.
  • RGB uses red, green, and blue values.
  • RGBA adds transparency to RGB.
  • HSL uses hue, saturation, and lightness.
