1. CSS Color Formats

CSS accepts named colors, hexadecimal notation, RGB, and HSL. Alpha variants such as RGBA control the transparency of the color itself without making child text translucent.

RGB

RGB combines red, green, and blue light intensities. Each channel ranges from 0 to 255, allowing 256 x 256 x 256, or 16,777,216, combinations.

color: rgb(255, 0, 0);       /* red */
color: rgb(0, 255, 0);       /* green */
color: rgb(0, 0, 0);         /* black */
color: rgb(255, 255, 255);   /* white */

RGBA alpha values

  • 0 or 0.0: completely transparent.
  • 0.5: semi-transparent.
  • 1 or 1.0: fully opaque.

HSL

  • Hue: the color angle, commonly described from 0 to 360 degrees.
  • Saturation: the intensity of the color, expressed as a percentage.
  • Lightness: how light or dark the color is, expressed as a percentage.

2. Text Color and Background Color

Use color for text and background-color for an element's background.

h1 {
    color: #174f78;
}

.notice {
    background-color: #e8f2f8;
}

3. Background Properties

PropertyPurpose
background-colorFills an element with a solid color.
background-imagePlaces one or more images or gradients behind content.
background-repeatControls image tiling: repeat, repeat-x, repeat-y, or no-repeat.
background-positionSets where the image begins, for example center or right top.
background-sizeControls image dimensions; cover fills the box, while contain shows the whole image.
background-attachmentControls whether the background scrolls with the element or viewport.
.banner {
    background-color: #174f78;
    background-image: linear-gradient(120deg, #174f78, #31765e);
    background-repeat: no-repeat;
    background-position: center;
    background-size: cover;
}
