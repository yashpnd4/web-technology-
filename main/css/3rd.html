CSS Colors and Backgrounds

1. CSS Color Values

CSS colors are used to change the text color and background color of HTML elements. Colors can be written using color names, HEX, RGB, RGBA, HSL, and HSLA values.

A. Color Names

CSS supports common color names such as red, blue, green, black, white, and tomato.

h1 {
    color: red;
}

B. HEX Colors

HEX colors use hexadecimal values. A common HEX color has a hash sign followed by six digits or letters. The six values represent red, green, and blue components. 

p {
    color: #0000FF;
}

C. RGB Colors

RGB stands for Red, Green, and Blue. Each color value normally ranges from 0 to 255. Different combinations create different colors. 

h1 {
    color: rgb(255, 0, 0);
}

Examples of RGB colors:

  • rgb(255, 0, 0) - Red
  • rgb(0, 255, 0) - Green
  • rgb(0, 0, 255) - Blue
  • rgb(0, 0, 0) - Black
  • rgb(255, 255, 255) - White

When all three RGB values are equal, the result is a shade of gray. Values near 0 create darker gray, while values near 255 create lighter gray. 

color: rgb(60, 60, 60);
color: rgb(140, 140, 140);
color: rgb(240, 240, 240);

D. RGBA Colors

RGBA stands for Red, Green, Blue, and Alpha. The alpha value controls the transparency of the color. It ranges from 0 (fully transparent) to 1 (fully opaque). 

p {
    color: rgba(255, 0, 0, 0.5);
}

The alpha value changes the color itself. It does not automatically make the text or other child elements transparent.

E. HSL and HSLA Colors

HSL stands for Hue, Saturation, and Lightness. HSLA also includes an alpha value for transparency.

  • Hue: The color angle, commonly from 0 to 360 degrees.
  • Saturation: The intensity of the color, written as a percentage.
  • Lightness: How light or dark the color is, written as a percentage.
  • Alpha: Controls transparency in HSLA.
h1 {
    color: hsl(9, 100%, 64%);
}

p {
    color: hsla(9, 100%, 64%, 0.5);
}

2. Text Color and Background Color

The color property changes the text color of an element. The background-color property changes the background color. 

h1 {
    color: tomato;
}

body {
    background-color: lightblue;
}

Choose text and background colors with enough contrast so the content remains easy to read.

3. Background Image

The background-image property is used to set an image as the background of an element. A background color can be kept as a fallback in case the image does not load. 

body {
    background-color: lightblue;
    background-image: url("image.jpg");
}

4. Background Properties

Property Use
background-color Sets the background color of an element.
background-image Sets a background image or gradient.
background-repeat Controls image tiling: repeat, repeat-x, repeat-y, or no-repeat.
background-position Sets where the image begins, such as center or right top.
background-size Controls image size. Cover fills the box; contain shows the whole image.
background-attachment Controls whether the background scrolls with the element or stays fixed.

Background Repeat Values

  • repeat: Repeats the image horizontally and vertically.
  • repeat-x: Repeats the image horizontally.
  • repeat-y: Repeats the image vertically.
  • no-repeat: Displays the image only once.

Example of Background Properties

body {
    background-color: lightblue;
    background-image: url("image.jpg");
    background-repeat: no-repeat;
    background-position: center;
    background-size: cover;
    background-attachment: fixed;
}

5. CSS Gradient

A gradient is a smooth change from one color to another. A linear gradient is created with the linear-gradient() function. It is treated as a background image created by CSS. 

.banner {
    background-color: #174f78;
    background-image: linear-gradient(120deg, #174f78, #31765e);
    background-repeat: no-repeat;
    background-position: center;
    background-size: cover;
}

6. Important Points

  • Use color to change text color.
  • Use background-color to change background color.
  • CSS supports named, HEX, RGB, RGBA, HSL, and HSLA colors.
  • RGB uses red, green, and blue values.
  • RGBA adds an alpha value for transparency.
  • HSL uses hue, saturation, and lightness.
  • Background properties control images, repeating, position, size, and attachment.
  • Gradients create a smooth change between colors.
