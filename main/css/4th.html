CSS Text, Fonts, Borders and Box Model

1. CSS Text and Font Properties

CSS provides different properties to change the appearance of text. We can change the font, size, weight, alignment, line spacing, and decoration.

Property Use
font-familyChanges the type of font.
font-sizeChanges the size of text.
font-weightChanges the thickness of text.
text-alignAligns text to left, right, or center.
line-heightSets the space between lines of text.
text-decorationAdds underline, overline, or line-through.
text-transformChanges text to uppercase or lowercase visually.

Example:

h1 {
    font-family: Arial;
    font-size: 30px;
    font-weight: bold;
    text-align: center;
}

p {
    line-height: 1.6;
    text-decoration: underline;
    text-transform: uppercase;
}

2. CSS Borders

The CSS border property is used to create a border around an HTML element. A border has width, style, and color.

Syntax:

border: width style color;

Example:

p {
    border: 2px solid red;
}

Common Border Styles

Border Style Meaning
solidA single solid line.
dottedA dotted line.
dashedA dashed line.
doubleA double line.
noneNo border is displayed.

Border Example:

h1 {
    border: 3px dashed blue;
}

p {
    border: 2px solid green;
}

The border shorthand can also use one to four values. When four values are given, they are applied in this order: top, right, bottom, and left. 

div {
    border-width: 2px 4px 6px 8px;
    border-style: solid;
    border-color: black;
}

The border-radius property can make the corners rounded. 

div {
    border: 2px solid blue;
    border-radius: 10px;
}

3. CSS Box Model

The CSS box model describes how space is arranged around every HTML element. It has four main parts: content, padding, border, and margin.

  1. Content: The actual text, image, or other content inside the element.
  2. Padding: The space between the content and the border.
  3. Border: The line around the padding and content.
  4. Margin: The space outside the border that separates elements.

Box Model Example:

div {
    width: 300px;
    padding: 20px;
    border: 5px solid black;
    margin: 10px;
}

4. Box Sizing

By default, CSS uses content-box. In this method, the width applies only to the content. Padding and border are added to it.

With border-box, the declared width includes the content, padding, and border. 

div {
    box-sizing: border-box;
}

A common practice is to apply border-box sizing to all elements. The before and after pseudo-elements can be included as well. 

*, *::before, *::after {
    box-sizing: border-box;
}

Example of Width Calculation

If an element has a content width of 300px, left and right padding of 20px each, and a 5px border on both sides, its total width with content-box is 350px (300 + 40 + 10). Margin is added outside this width.

In normal block layout, vertical margins of two neighboring block elements can sometimes collapse into one margin instead of being added together.

5. Important Points

  • Font properties control the appearance of text.
  • The border property creates a line around an element.
  • The box model contains content, padding, border, and margin.
  • Padding is inside the border, while margin is outside the border.
  • Border-box makes width calculations easier.
  • Vertical margins of neighboring block elements may collapse.
