CSS Syntax, Selectors and Values

← Back to CSS Overview

1. CSS Syntax

A CSS rule contains a selector and a declaration block. The selector selects the HTML element, while the declaration block contains properties and their values.

Basic Syntax:

selector {
    property: value;
}

Example:

p {
    color: red;
    font-size: 20px;
}
  • Selector: Selects the HTML element.
  • Property: The feature to change, such as color or font-size.
  • Value: The setting given to the property, such as red or 20px.

2. Types of CSS Selectors

A. Element Selector

It selects all HTML elements of the given type.

p {
    color: blue;
}

B. Class Selector

It selects all elements having the given class name. A class selector starts with a dot (.).

.notice {
    color: green;
}

HTML example: <p class="notice">Important message</p>

C. ID Selector

It selects the element having the given ID. An ID selector starts with a hash (#).

#heading {
    color: red;
}

HTML example: <h1 id="heading">Welcome</h1>

D. Universal Selector

It selects all elements on the webpage. It uses the asterisk (*) symbol.

* {
    margin: 0;
}

E. Group Selector

It applies the same CSS rules to more than one selector.

h1, h2, p {
    color: navy;
}

F. Descendant Selector

It selects elements that are present anywhere inside another element.

div p {
    color: green;
}

G. Child Selector

It selects only the direct child elements of another element.

ul > li {
    color: blue;
}

H. Pseudo-class Selector

It applies a style when an element is in a particular state, such as when the mouse pointer is over a link.

a:hover {
    color: red;
}

I. Pseudo-element Selector

It is used to style a specific part of an element.

p::first-line {
    font-weight: bold;
}

J. Attribute Selector

It selects elements based on an attribute or its value.

input[type="text"] {
    border-color: blue;
}

3. CSS Units

CSS units are used to define sizes, spacing, and dimensions.

Unit Meaning Example
pxPixel unitfont-size: 20px;
emRelative to the element's font size (or parent for font-size)padding: 2em;
remRelative to the root element's font sizefont-size: 2rem;
%Percentage of a value determined by the propertywidth: 80%;
vwPercentage of viewport widthwidth: 50vw;
vhPercentage of viewport heightheight: 50vh;

4. CSS Variables

CSS variables are also called custom properties. They store values that can be reused in different CSS rules. Their names begin with two hyphens and they are used with the var() function. 

:root {
    --main-color: blue;
}

h1 {
    color: var(--main-color);
}

5. Cascade and Inheritance

Cascade: When more than one CSS rule applies to the same element, the browser decides which rule should be used. Importance, selector specificity, and source order are considered.

Inheritance: Some properties, such as color and font-family, can pass from a parent element to its child elements. Properties such as margin, padding, and border do not normally inherit. 

body {
    color: black;
}

p {
    color: blue;
}
