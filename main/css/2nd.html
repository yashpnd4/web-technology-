1. CSS Rule Syntax

A CSS rule has a selector followed by a declaration block. Each declaration pairs a property with a value.

p.notice {
    color: #153c5b;
    background-color: #e8f2f8;
    border-left: 5px solid #2196f3;
    padding: 14px;
}
Rendered example

CSS applies this rule to a paragraph whose class includes notice.

  • Selector: chooses the element or elements to style.
  • Property: identifies what is being changed, such as color.
  • Value: specifies the setting, such as #153c5b.
  • Declaration: a property and value written together, ending with a semicolon.

2. Common CSS Selectors

SelectorWhat it matchesExample
Element: pEvery paragraph element.p { line-height: 1.6; }
Class: .noticeEvery element with class="notice"..notice { padding: 1rem; }
ID: #main-titleThe element with that ID.#main-title { color: navy; }
Universal: *All elements.* { box-sizing: border-box; }
Grouping: h1, h2Both heading types.h1, h2 { color: navy; }
Descendant: nav aLinks anywhere inside a navigation element.nav a { text-decoration: none; }
Child: ul > liList items that are direct children of a list.ul > li { margin-block: .5rem; }
Pseudo-class: a:hoverA link while the pointer is over it.a:hover { color: green; }
Pseudo-element: p::first-lineA specific part of an element.p::first-line { font-weight: bold; }
Attribute: input[type="email"]Email inputs.input[type="email"] { border-color: teal; }

3. CSS Values and Units

A property only has an effect when it receives a valid value. Values may be keywords, colors, numbers, lengths, percentages, or functions.

UnitRelative toCommon use
pxA CSS pixel, a reference unit rather than necessarily one physical screen pixel.Fine borders and small fixed details.
remThe root element's font size.Consistent, scalable typography and spacing.
emThe computed font size of the element; for font-size, it is relative to the parent.Spacing that scales with text.
%A context determined by the property, often a parent dimension.Flexible widths and proportional sizing.
vw / vhOne percent of viewport width or height.Sizing related to the visible browser area.
.page-title {
    font-size: 2rem;
    max-width: 80%;
}

.hero {
    min-height: 60vh;
    padding: 2em;
}

4. Custom Properties (CSS Variables)

Custom properties store reusable values. Their names begin with two hyphens and values are read with var(). Defining shared values on :root makes them available throughout the document.

:root {
    --brand-color: #174f78;
    --space-medium: 1rem;
}

.notice {
    color: var(--brand-color);
    padding: var(--space-medium);
}

5. How the Cascade Chooses a Value

If several rules set the same property, the browser resolves the cascade by importance and origin, selector specificity, and then source order. A later rule wins only when the earlier comparisons are tied.

p {
    color: #333;          /* element selector */
}

.notice {
    color: #174f78;       /* class selector: more specific */
}

#warning {
    color: #a34b00;       /* ID selector: more specific still */
}

Inline styles commonly outrank normal stylesheet rules, but they are not an unconditional highest priority.

6. Inheritance and Debugging

Some properties, especially text-related properties such as color and font-family, are inherited. A child can use the computed value of its parent when it has no value of its own.

Many layout and box properties, such as margin, padding, and border, do not inherit by default. Inheritance is separate from specificity.

.article {
    color: #24313d;
    border: 1px solid #d7e0e5;
}

.article p {
    /* The paragraph inherits color, but not the border. */
    font-family: Georgia, serif;
}
Debugging tip: Browsers generally ignore an invalid declaration and continue parsing. Check spelling, values, braces, and semicolons when a style does not appear.
