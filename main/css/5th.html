CSS Positioning

← Back to CSS Overview

1. What is CSS Positioning?

CSS positioning is used to control where an HTML element appears on a webpage. The position property decides how an element is placed in the document.

2. Types of CSS Positioning

A. Static Positioning

Static is the default position of HTML elements. Elements appear in the normal order of the webpage. The top, right, bottom, and left properties do not move a static element. 

div {
    position: static;
}

B. Relative Positioning

A relatively positioned element is moved from its normal position. Its original space remains in the document. 

div {
    position: relative;
    top: 10px;
    left: 20px;
}

C. Absolute Positioning

An absolutely positioned element is removed from the normal document flow. It is positioned relative to its nearest positioned ancestor. 

.parent {
    position: relative;
}

.child {
    position: absolute;
    top: 10px;
    right: 10px;
}

D. Fixed Positioning

A fixed element is positioned relative to the browser window. It stays in the same place when the page is scrolled. 

div {
    position: fixed;
    top: 10px;
    right: 10px;
}

E. Sticky Positioning

Sticky positioning works like relative positioning until the element reaches a specified scroll position. It then sticks within its scrolling container. A top, right, bottom, or left offset is normally needed to tell the browser where it should stick. 

h2 {
    position: sticky;
    top: 0;
}

3. Difference Between Positioning Types

Position Meaning
StaticNormal position of an element.
RelativeMoves from its normal position and keeps its original space.
AbsoluteMoves relative to the nearest positioned ancestor and leaves normal flow.
FixedStays at a position relative to the browser window.
StickyMoves normally and sticks after reaching a scroll point.

Positioning Example

In this example, the parent element is positioned relatively. The child element is positioned absolutely, so the child uses the parent as its reference point. 

.parent {
    position: relative;
}

.child {
    position: absolute;
    top: 12px;
    right: 12px;
}

A fixed element is positioned relative to the viewport. A sticky element stays within its scrolling container after reaching its offset.

4. Important Points

  • top, right, bottom, and left are used to set position offsets.
  • Static is the default positioning value.
  • Relative positioning keeps the element's original space.
  • Absolute positioning uses a positioned ancestor as its reference when available.
  • Fixed positioning is related to the viewport.
