CSS Positioning

Understand how static, relative, absolute, fixed, and sticky positioning affect an element's place in the document.

LESSON 05

1. Positioning Values

The CSS position property determines how an element is placed in the document. Some values keep an element in normal flow, while others take it out of normal flow.

ValueHow it behaves
staticDefault position in normal document flow; offsets do not apply.
relativeRemains in flow and moves from its normal position; its original space remains.
absoluteLeaves normal flow and uses the nearest positioned ancestor as its containing block.
fixedLeaves normal flow and is positioned relative to the viewport.
stickyActs relative until a scroll threshold, then sticks within its scrolling container.

2. Static and Relative Positioning

.normal-box {
    position: static;
}

.moved-box {
    position: relative;
    top: 10px;
    left: 12px;
}
Static
Normal flow
Relative
Moved; original space is kept

A relatively positioned element remains in the normal flow. Its original space is retained even when it is visually moved.

3. Absolute Positioning

An absolutely positioned element is positioned relative to its nearest positioned ancestor. A common pattern is to give the parent position: relative and place a label or badge inside it using position: absolute.

.card {
    position: relative;
}

.card-badge {
    position: absolute;
    top: 12px;
    right: 12px;
}
Parent with position: relative
Badge Card content

The badge is anchored to this card, not to the page.

Key point: In this example, the parent box has position: relative. That makes the absolutely positioned label anchor to its box instead of the page.

4. Fixed and Sticky Positioning

Fixed

A fixed element is positioned relative to the viewport and stays in that position while the page scrolls. It does not keep its normal-flow space.

.help-button {
    position: fixed;
    right: 20px;
    bottom: 20px;
}

Sticky

A sticky element behaves like a relatively positioned element until it reaches a specified scroll threshold, after which it sticks within its scrolling container.

.section-heading {
    position: sticky;
    top: 0;
}
