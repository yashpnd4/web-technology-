Need for CSS and Ways to Add CSS

← Back to CSS Overview

1. What is CSS?

CSS stands for Cascading Style Sheets. It is a stylesheet language used to describe how HTML elements should be displayed on a webpage. CSS controls colors, fonts, spacing, borders, backgrounds, and layout.

2. Why CSS is Needed

  • Separate Content and Design: HTML is used for content and CSS is used for design.
  • Same Design on Many Pages: One CSS file can be connected to multiple HTML pages.
  • Easy Maintenance: We can change the design by editing CSS rules instead of changing every HTML element.
  • Responsive Pages: CSS can help webpages adjust to different screen sizes.
  • Less Repetition: The same styles can be reused by different elements.

3. Three Ways to Add CSS

A. Inline CSS

Inline CSS is written inside the style attribute of an HTML element. It is generally used to apply a style to one particular element. 

<p style="color: red;">This is a red paragraph.</p>

B. Internal CSS

Internal CSS is written inside the <style> tag in the <head> section of an HTML document. It is useful when one page needs its own styles. 

<html>
<head>
    <title>Internal CSS</title>
    <style>
        h1 {
            color: blue;
        }
    </style>
</head>
<body>
    <h1>Welcome</h1>
</body>
</html>

C. External CSS

External CSS is written in a separate file with the .css extension. The CSS file is connected to the HTML page using the <link> tag inside the <head>. It is useful when many pages share the same design. 

<html>
<head>
    <title>External CSS</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <h1>Welcome</h1>
</body>
</html>

Example of style.css:

h1 {
    color: green;
}

4. Difference Between the Three Methods

Method Where CSS is Written Use
Inline CSS Inside the style attribute For one HTML element
Internal CSS Inside the style tag in the head For one webpage
External CSS In a separate .css file For multiple webpages

5. Important Points

  • CSS makes webpages attractive and easy to read.
  • External CSS helps maintain the same design on different pages.
  • Inline CSS applies to a particular HTML element.
  • Internal CSS is written inside the head section.
