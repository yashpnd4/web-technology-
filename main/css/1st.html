1. What Is CSS?

CSS stands for Cascading Style Sheets. HTML describes the structure and meaning of a page, while CSS controls its visual presentation: colors, typography, spacing, borders, and layout.

Remember: HTML supplies the content and structure. CSS controls how that content looks and is arranged.

2. Why CSS Is Needed

Separate content and design

Keep meaningful headings, paragraphs, lists, and forms in HTML. Put visual rules in CSS instead of repeating presentation attributes on every element.

Reuse one design

A single external stylesheet can style many pages. Updating one rule can keep an entire website consistent.

Adapt to different screens

Media queries and flexible layouts allow the same content to work on phones, tablets, and desktop displays.

Reduce repeated work

Reusable selectors avoid copying the same declarations into every HTML document. Browsers can also cache external stylesheets.

4. Three Ways to Add CSS

A. External stylesheet

Write CSS in a separate file, for example styles.css, and connect it from the HTML <head>. This is suitable for shared site-wide styles and maintainable projects.

<!-- Place this inside the HTML <head> -->
<link rel="stylesheet" href="styles.css">
/* styles.css */
h1 {
    color: #174f78;
}

B. Internal stylesheet

Place a <style> element in the document's <head>. It is useful when styles are intended for one standalone page.

<head>
    <style>
        h1 {
            color: #174f78;
        }
    </style>
</head>

C. Inline style

Use the style attribute on one HTML element. It is useful for a small one-off demonstration, but should not be repeated across many elements.

<p style="color: #31765e;">Styled text</p>
Best practice: Prefer an external stylesheet when several pages share the same design. Use internal CSS for a single-page exercise and inline CSS only for a specific one-off example.
