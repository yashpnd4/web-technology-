Introduction to XML

1. What is XML?

XML stands for Extensible Markup Language. It is a text-based markup language used for representing, storing, and transporting structured data. XML allows authors to create descriptive tags that match their data.

XML describes the meaning of information rather than how it should look on a screen. Another program or stylesheet can decide how the information is used or displayed.

2. Example of an XML Document

The following XML represents a course record:

<course code="WT205">
    <title>Web Technologies</title>
    <credits>4</credits>
    <instructor>Dr. Mehta</instructor>
</course>

The element names course, title, credits, and instructor describe the information stored in the document. The code value is an attribute.

3. Features of XML

  • Extensible: Authors can choose meaningful element and attribute names. XML does not prescribe one fixed set of tags.
  • Structured: Elements are nested in a tree and can contain related child records.
  • Portable: XML is text that can be read by people and processed by software on different platforms.
  • Flexible: XML can represent many kinds of structured information.
  • Data format: XML is a markup and data format, not a programming language.

4. Difference Between XML and HTML

HTML XML
Uses predefined tags. Allows users to define their own tags.
Used to structure and display webpage content. Used to describe, store, and transport structured data.
Browsers have built-in meanings for standard HTML elements. Element names describe the data and do not automatically create a styled user interface.
HTML tag names are generally not case-sensitive in HTML syntax. XML element names are case-sensitive.

5. Well-Formed XML and Valid XML

A well-formed XML document follows the basic XML syntax rules. It has one root element, properly nested and closed tags, and quoted attribute values.

A valid XML document is well-formed and also follows a declared grammar, such as a DTD or XML Schema (XSD).

Well-Formed Valid
Follows XML syntax rules. Follows XML syntax rules and a declared DTD or XSD.
Does not require a DTD or XSD. Must conform to the declared grammar.

6. Where XML is Used

  • Exchanging structured data between applications and services.
  • Configuration files and document formats.
  • Feeds such as RSS.
  • Representing information where explicit structure and readability are important.

7. Important Points

  • XML stands for Extensible Markup Language.
  • XML is used to store and transport structured data.
  • XML allows custom tags.
  • XML is not a programming language and is not the same as HTML.
  • A valid XML document must also be well-formed.
