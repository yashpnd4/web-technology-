Extensible Markup Language (XML)

Structure, Validation, and Transformation

Introduction

XML stands for Extensible Markup Language. It is a text-based markup language used to represent, store, and transport structured data. XML allows users to create their own descriptive tags according to the information they want to store.

HTML uses predefined tags to display a webpage, while XML uses custom tags to describe data. XML describes what information means; another program or stylesheet decides how to use or display it.

Important Points

  • XML is used to store and exchange structured data.
  • XML allows custom element and attribute names.
  • An XML document must be well-formed.
  • DTD and XSD can be used to validate XML documents.
  • XSLT can transform XML into HTML, XML, or text.
