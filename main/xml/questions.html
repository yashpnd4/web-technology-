XML Questions and Answers

Basic XML Questions and Answers

These 15 questions cover Unit 5: XML purpose, syntax, components, namespaces, DTD, XML Schema, XPath, XSL, and XSLT.

1. What is XML?

Answer: XML stands for Extensible Markup Language. It is a text-based markup language used to represent, store, and transport structured data. XML allows users to create their own descriptive tags.

2. What are the main features and uses of XML?

Answer: XML is extensible, structured, and portable. It is used for:

  • Exchanging structured data between applications and services.
  • Configuration files and document formats.
  • Feeds such as RSS.
  • Representing information where readability and explicit structure matter.

3. What is the difference between XML and HTML?

Answer:

  • HTML: Uses predefined tags to structure and display webpage content.
  • XML: Allows custom tags and is used to describe, store, and transport structured data.
  • HTML elements have browser-defined meaning and presentation. XML tags describe the data and do not automatically create a styled interface.

4. What is the difference between well-formed XML and valid XML?

Answer: Well-formed XML follows XML syntax rules, such as one root element, correct nesting, closed tags, and quoted attributes. Valid XML is well-formed and also follows a declared grammar such as DTD or XSD.

5. What is the basic structure of an XML document?

Answer: An XML document can contain an XML declaration, one root element, nested child elements, attributes, text, and comments.

<?xml version="1.0" encoding="UTF-8"?>
<student id="s101">
    <name>Mira</name>
    <marks>88</marks>
</student>

6. What are XML elements and attributes?

Answer: An element is a named unit of data, normally written with a start tag and an end tag. An attribute gives extra information in the start tag as a name and value pair. 

<student id="s101">
    <name>Mira</name>
</student>

Here, student and name are elements, while id is an attribute.

7. State the important syntax rules of XML.

Answer:

  • Element names are case-sensitive.
  • Every opened element must be closed or use empty-element syntax.
  • Elements must be properly nested.
  • There must be exactly one root element.
  • Attribute values must be quoted.

8. What are XML comments and reserved characters?

Answer: Comments provide notes for readers and are not part of the XML data content. Comments use this syntax:

<!-- This is an XML comment -->

Reserved characters are represented using entity references when needed:

  • &amp; represents &.
  • &lt; represents <.
  • &gt; represents >.

9. What are XML namespaces?

Answer: XML namespaces prevent naming collisions when elements from different vocabularies are combined. A prefix is connected to a namespace URI using the xmlns attribute. 

<course xmlns:lib="https://example.edu/library">
    <title>Web Technologies</title>
    <lib:title>XML for Libraries</lib:title>
</course>

10. What is DTD?

Answer: DTD stands for Document Type Definition. It defines the allowed elements, attributes, entities, and content models of an XML document. It can be internal or stored in an external .dtd file.

11. What are DTD element and attribute declarations?

Answer: DTD uses declarations to define the content of elements and their attributes.

<!ELEMENT catalog (product+)>
<!ELEMENT product (name, price)>
<!ATTLIST product id ID #REQUIRED>
<!ELEMENT name (#PCDATA)>
<!ELEMENT price (#PCDATA)>

This example requires one or more product elements with a name, price, and required id attribute.

12. What is XML Schema (XSD)?

Answer: XSD stands for XML Schema Definition. It is an XML-based language used to define the structure and data types of an XML document. It supports built-in types such as decimal and date, constraints, namespaces, and reusable type definitions.

13. What is the difference between DTD and XSD?

Answer:

  • DTD uses specialized DTD syntax; XSD is written in XML.
  • DTD has limited data types; XSD supports built-in and custom types.
  • DTD has limited namespace support; XSD is designed for namespaces.
  • XSD is more expressive and strongly typed than DTD.

14. What are XSL, XPath, and XSLT?

Answer:

  • XSL: Extensible Stylesheet Language, a family of technologies for working with XML.
  • XPath: Expressions used to select nodes and values in XML.
  • XSLT: Extensible Stylesheet Language Transformations, used to transform XML into HTML, XML, or text.
  • XSL-FO: Formatting objects commonly used for paginated output.

15. What are xsl:template, xsl:for-each, and xsl:value-of?

Answer:

  • xsl:template defines a transformation rule for selected nodes.
  • xsl:for-each selects nodes using XPath and repeats the enclosed output.
  • xsl:value-of reads the value of a selected element or attribute.

An XML file can be connected to an XSLT file using the xml-stylesheet processing instruction. The study guide also shows running a transformation with xsltproc catalog.xsl catalog.xml.
