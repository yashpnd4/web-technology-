XML Key Components and Namespaces

1. XML Document Structure

An XML document is represented as a tree of nodes. It can contain an XML declaration, one root element, nested elements, attributes, text values, and comments. 

<?xml version="1.0" encoding="UTF-8"?>
<student id="s-204" status="active">
    <name>Mira Shah</name>
    <programme>B.Tech CSE</programme>
    <marks subject="XML">88</marks>
    <!-- A student record -->
</student>

2. Main Components of XML

Component Meaning Example
XML Declaration Optional first line that identifies the XML version and character encoding. <?xml version="1.0" encoding="UTF-8"?>
Element A named unit of data. It can contain text, attributes, or other elements. <name>Mira</name>
Root Element The single outermost element containing all other elements. <student>...</student>
Attribute Metadata written in a start tag as a name and value pair. id="s-204"
Text Node Character data between a start tag and its matching end tag. 88
Comment A note for readers. It is not part of the document's data content. <!-- Student record -->

3. XML Syntax Rules

  1. XML element names are case-sensitive. For example, Name and name are different.
  2. Every opened element must be closed, or use empty-element syntax such as <image/>.
  3. Elements must be properly nested. Incorrect nesting makes the document not well-formed.
  4. There must be exactly one root element in an XML document.
  5. Attribute values must be written inside quotes.
  6. Reserved characters in text must be escaped when required.

Correct Nesting Example

<student>
    <name>Mira</name>
</student>

Incorrect Nesting Example

<b><i>Text</b></i>

4. Reserved XML Characters

Some characters have special meaning in XML. Use the following entity references when these characters need to appear as text.

Character XML Entity
&&amp;
<&lt;
>&gt;

5. XML Namespaces

XML namespaces prevent naming collisions when XML elements from different vocabularies are combined. A namespace prefix is connected to a URI using the xmlns attribute. The URI identifies the vocabulary; it does not have to be a working webpage. 

<course xmlns:lib="https://example.edu/library">
    <title>Web Technologies</title>
    <lib:title>XML for Libraries</lib:title>
</course>

In this example, title and lib:title are different names because lib:title belongs to the library namespace.

6. Important Points

  • An XML document has one root element.
  • XML names are case-sensitive.
  • Every element must be properly closed and nested.
  • Attribute values must be quoted.
  • Namespaces prevent naming conflicts.
