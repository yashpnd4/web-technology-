Transforming XML using XSL, XPath and XSLT

1. What is XSL?

XSL stands for Extensible Stylesheet Language. It is a family of technologies used for working with XML documents.

Its main parts are:

  • XSLT: Rules and instructions for transforming XML documents.
  • XPath: Expressions used to select nodes and values from an XML document.
  • XSL-FO: Formatting objects commonly used for paginated output.

In introductory materials, the term XSL is sometimes used informally to mean an XSLT stylesheet.

2. What is XSLT?

XSLT stands for Extensible Stylesheet Language Transformations. It reads a source XML tree, selects nodes using XPath, and applies template rules to create a result.

XSLT can transform XML into:

  • HTML for displaying information on a webpage.
  • Another XML document.
  • Plain text.

XSLT changes the representation of the data; it does not change the source XML document.

3. Example Source XML

<catalog>
    <book id="b101">
        <title>Learning XML</title>
        <author>Asha Rao</author>
        <price>450</price>
    </book>
    <book id="b102">
        <title>Data on the Web</title>
        <author>Neil Patel</author>
        <price>525</price>
    </book>
</catalog>

4. Example XSLT 1.0 Stylesheet

The following stylesheet selects each book and creates an HTML table. 

<xsl:stylesheet version="1.0"
    xmlns:xsl="http://www.w3.org/1999/XSL/Transform">

    <xsl:output method="html" indent="yes"/>

    <xsl:template match="/">
        <table>
            <tr>
                <th>ID</th>
                <th>Title</th>
                <th>Author</th>
                <th>Price</th>
            </tr>

            <xsl:for-each select="catalog/book">
                <tr>
                    <td><xsl:value-of select="@id"/></td>
                    <td><xsl:value-of select="title"/></td>
                    <td><xsl:value-of select="author"/></td>
                    <td><xsl:value-of select="price"/></td>
                </tr>
            </xsl:for-each>
        </table>
    </xsl:template>

</xsl:stylesheet>

5. Important XSLT Elements

Element Purpose
<xsl:template match="/"> Starts a template at the document root.
<xsl:for-each> Selects nodes with an XPath expression and repeats the enclosed output for each selected node.
<xsl:value-of> Reads the value of a selected element or attribute.
<xsl:output> Specifies the output method, such as HTML.

In the example, @id selects the id attribute of each book, while title, author, and price select child elements.

6. Connecting XML to an XSLT File

A standalone XML file can be connected to an XSLT stylesheet using the xml-stylesheet processing instruction. 

<?xml version="1.0" encoding="UTF-8"?>
<?xml-stylesheet type="text/xsl" href="catalog.xsl"?>
<catalog>
    <book id="b101">
        <title>Learning XML</title>
        <author>Asha Rao</author>
        <price>450</price>
    </book>
</catalog>

7. Running an XSLT Transformation

The study guide shows the xsltproc command for a local command-line demonstration. Save the source XML as catalog.xml and the stylesheet as catalog.xsl. 

xsltproc catalog.xsl catalog.xml

The transformed HTML is written to standard output. xsltproc is available with libxslt.

The guide also describes a browser example using DOMParser and XSLTProcessor with XSLT 1.0. It notes that Chromium warns that browser XSLT support is deprecated and may be removed. For a durable local demonstration, the guide recommends using xsltproc.

8. Important Points

  • XSL is a family of XML technologies.
  • XPath selects nodes and values from XML documents.
  • XSLT transforms XML into HTML, XML, or text.
  • xsl:template defines a transformation rule.
  • xsl:for-each repeats output for selected nodes.
  • xsl:value-of reads element or attribute values.
  • XML can be connected to an XSLT stylesheet using xml-stylesheet.
