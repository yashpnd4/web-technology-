Color Values in HTML

In HTML, colors can be specified using RGB, HEX, HSL, and translucent RGBA or HSLA values.

HTML RGB and RGBA Colors

RGB Color Model

An RGB color value represents RED, GREEN, and BLUE light sources combined to create various colors.

RGB Color Values

In HTML, colors are defined by combining Red, Green, and Blue light intensities.

Formula: rgb(red, green, blue)

  • Each parameter defines the light intensity as a value between 0 and 255.
  • 256 values per channel
  • 256 x 256 x 256 combinations
  • 16,777,216 possible colors
Color RGB Value
Red rgb(255, 0, 0)
Green rgb(0, 255, 0)
Black rgb(0, 0, 0)
White rgb(255, 255, 255)

Shades of Gray

Shades of gray are defined using equal values for all three RGB parameters.

The Gray Rule: rgb(X, X, X)

When red, green, and blue values are completely equal, the color saturations cancel out, resulting in a neutral gray.

  • Values closer to 0 create darker shades
  • Values closer to 255 create lighter shades
  • Total of 256 unique gray levels

RGBA Color Values

An RGBA color value is an extension of RGB with an Alpha channel which specifies the opacity of the color.

The Alpha Parameter: rgba(R, G, B, alpha)

  • 0.0 - Completely invisible (transparent)
  • 0.5 - Semi-transparent
  • 1.0 - Fully opaque (solid color)

HTML HEX Colors

A hexadecimal representation of RGB values used to specify colors in HTML.

The HEX Rule: #RRGGBB

A hexadecimal color is specified with six hexadecimal digits, where RR (red), GG (green), and BB (blue) specify the components.

  • RR (Red): Specifies red intensity (00 to FF)
  • GG (Green): Specifies green intensity (00 to FF)
  • BB (Blue): Specifies blue intensity (00 to FF)

Green #00FF00
Blue #0000FF

HTML HSL and HSLA Colors

Intuitive color models in modern web development offering precision control over lighting and opacity.

HSL Color Model

Represents color values based on three primary visual dimensions:

  • Hue: Positioned on a 360° color wheel from red, through green and blue, and back to red.
  • Saturation: Intensity value from 0% (grayscale shadow) up to 100% (full vibrant color).
  • Lightness: Brightness level from 0% (pure black) up to 100% (pure white).

HSLA Color Model

Extends the standard HSL color model by introducing opacity control.

  • Alpha Channel: Specifies the level of transparency for rendering the element.
  • Numeric Range: Expressed as a decimal between 0.0 (fully transparent) and 1.0 (completely opaque).
  • UI Design: Ideal for overlay filters, glassmorphism designs, and smooth backdrop blending layers.

HSL Color Values

An intuitive way to specify colors in HTML using Hue, Saturation, and Lightness.

Syntax: hsl(hue, saturation, lightness)

Hue

A degree on the color wheel from 0 to 360.

Value Color
0 Red
120 Green
240 Blue

Saturation

A percentage value that represents the color intensity.

Value Description
0% Shade of Gray
100% Full Color

Saturation can be described as the intensity of a color.

Level Value Description
LEVEL 1 100% Pure color, no shades of gray.
LEVEL 2 50% 50% gray, but you can still see the color.
LEVEL 3 0% Completely gray; you can no longer see the color.

HSLA Color Values

An extension of standard HSL color values, introducing an Alpha channel to specify color opacity.

Syntax: hsla(hue, saturation, lightness, alpha)

Parameter Range Description
Hue 0 to 360 Represents a degree on the color wheel from 0 to 360. 0 is red, 120 is green, and 240 is blue.
Saturation 0% to 100% A percentage value. 0% means a shade of gray, and 100% is the full, vibrant color.
Lightness 0% to 100% A percentage value. 0% is completely black, 50% is normal (neither dark nor light), and 100% is white.
Alpha 0.0 to 1.0 A number specifying opacity. 0.0 is fully transparent, and 1.0 is not transparent at all.
