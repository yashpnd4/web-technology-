Basic HTML Questions and Answers

These questions cover HTML basics, elements, attributes, formatting, colors, hyperlinks, lists, tables, images, forms, HTML5, and XML.

1. What is HTML?

Answer: HTML stands for HyperText Markup Language. It is the standard markup language used to create and structure webpages. It tells the browser what content to display, such as headings, paragraphs, images, links, lists, and forms.

2. What is the basic structure of an HTML document?

Answer: A basic HTML document contains the DOCTYPE declaration, html, head, title, and body elements.

<!DOCTYPE html>
<html>
<head>
    <title>My First Page</title>
</head>
<body>
    <h1>Welcome to HTML</h1>
    <p>This is my first webpage.</p>
</body>
</html>
  • DOCTYPE: Declares the document type.
  • html: The root element of the document.
  • head: Contains metadata and the page title.
  • title: Defines the title shown in the browser tab.
  • body: Contains the visible webpage content.

3. What is an HTML element? Explain empty and nested elements.

Answer: An HTML element normally contains a starting tag, content, and an ending tag. 

<p>Welcome to my website</p>

An empty element does not have content or a closing tag. Examples include <br>, <hr>, and <img>.

Nested elements are elements placed inside other elements. For example, a paragraph can contain bold text. 

<p>This is <b>bold</b> text.</p>

4. What are HTML attributes? Give common examples.

Answer: Attributes provide extra information or settings for HTML elements. They are written in the opening tag as name and value pairs.

Attribute Use
hrefSpecifies the destination of a hyperlink.
srcSpecifies the path or URL of an image or media file.
altProvides alternative text for an image.
width and heightSet the dimensions of elements such as images.
langDeclares the language of the document or element.
titleProvides extra information, often shown as a tooltip.
styleApplies inline CSS to an element.

5. What are HTML headings and paragraphs?

Answer: HTML provides six heading levels, from <h1> to <h6>. The h1 element is the main heading and h6 is the lowest heading level.

The <p> tag is used to define a paragraph. Browsers normally display paragraphs on a new line with space before and after them. 

<h1>Main Heading</h1>
<h2>Sub Heading</h2>
<p>This is a paragraph.</p>

6. Name some HTML text formatting tags.

Answer:

Tag Purpose
<b>Makes text bold.
<strong>Shows strong importance.
<i>Displays italic text.
<em>Emphasizes text.
<mark>Highlights text.
<small>Displays smaller text.
<del>Displays deleted text with a line through it.
<ins>Displays inserted text, usually underlined.
<sub> and <sup>Display subscript and superscript text.

7. What are the uses of br, hr, and pre tags?

Answer:

  • <br> - Inserts a line break.
  • <hr> - Creates a thematic break or horizontal rule.
  • <pre> - Preserves spaces and line breaks as written in the source code.

8. How can styles and colors be applied in HTML?

Answer: The HTML style attribute can apply CSS directly to an element. Common properties in the notes include background-color, color, font-family, font-size, text-align, and font-style. 

<h1 style="color:Tomato;">Heading</h1>
<p style="background-color:PowderBlue;">Paragraph</p>
<p style="font-family:Verdana; font-size:20px;">Text</p>

9. What are RGB, RGBA, HEX, HSL, and HSLA color values?

Answer:

  • RGB: Uses Red, Green, and Blue values from 0 to 255.
  • RGBA: RGB with an Alpha value for transparency, from 0 to 1.
  • HEX: Uses a hexadecimal value in the form #RRGGBB.
  • HSL: Uses Hue, Saturation, and Lightness.
  • HSLA: HSL with an Alpha value for transparency.
color: rgb(255, 0, 0);
color: rgba(255, 0, 0, 0.5);
color: #FF0000;
color: hsl(0, 100%, 50%);
color: hsla(0, 100%, 50%, 0.5);

10. What is a hyperlink? Explain common types of HTML links.

Answer: A hyperlink is a clickable text or image that takes the user to another page, resource, or location. The <a> tag creates a hyperlink and the href attribute gives its destination. 

<a href="https://example.com">Visit Website</a>

The HTML notes describe these link types:

  • Self link: Opens the same page.
  • Blank link: Opens the link in a new tab.
  • Parent link: Opens the parent page.
  • Top link: Moves to the top of the same page or website.
  • Email link: Uses an email address as the link destination.

11. What are the three types of HTML lists?

Answer:

  • Unordered List (<ul>): Displays items with bullet points.
  • Ordered List (<ol>): Displays items in a numbered sequence.
  • Description List (<dl>): Displays terms and their descriptions using dt and dd.
<ul>
    <li>Tea</li>
    <li>Coffee</li>
</ul>

<ol>
    <li>First</li>
    <li>Second</li>
</ol>

12. Explain the basic HTML table tags.

Answer: HTML tables are used to arrange data in rows and columns.

  • <table> - Defines the table.
  • <tr> - Defines a row.
  • <th> - Defines a header cell.
  • <td> - Defines a normal data cell.
  • <caption> - Defines the table title.
  • <thead>, <tbody>, and <tfoot> - Group the table's header, body, and footer rows.

13. How are images added in HTML? Explain the image attributes.

Answer: The <img> tag is used to display an image. It is an empty element and does not need a closing tag. 

<img src="flower.jpg" alt="Flower" width="300" height="200">
  • src: Specifies the path or URL of the image.
  • alt: Provides alternative text if the image cannot load and helps screen readers.
  • width: Sets the image width.
  • height: Sets the image height.

14. What is an HTML form? Name common form controls and HTML5 input types.

Answer: An HTML form collects user input such as text, passwords, selections, and choices. The <form> element contains the form controls.

  • type="text" - Creates a single-line text field.
  • type="radio" - Allows one option to be selected from a group.
  • type="checkbox" - Allows zero, one, or multiple options to be selected.
  • type="submit" - Creates a button to submit form data.
  • type="email" - Provides an email input with browser validation.
  • type="date" - Provides a date picker.
  • type="color" - Provides a color picker.
  • type="range" - Provides a slider.
  • type="number" - Provides a numerical input.

The <label> element describes an input. Its for attribute should match the input's id. Radio buttons in the same group share the same name. The form's action attribute specifies where the data is sent. 

<form action="submit.php">
    <label for="name">Name:</label>
    <input type="text" id="name" name="name">

    <input type="submit" value="Submit">
</form>

15. What are HTML5, XML, and XHTML?

Answer:

  • HTML5: Introduced semantic elements such as header, nav, main, article, section, aside, and footer.
  • Multimedia: HTML5 uses audio and video tags to play media in the browser. Common attributes include controls, autoplay, loop, and muted.
  • Drag and Drop: HTML5 allows elements to be dragged using draggable="true" and events such as ondragstart, ondragover, and ondrop.
  • XML: Extensible Markup Language, used to store and transport structured data. XML is case-sensitive and requires properly closed and nested tags, one root element, and quoted attribute values.
  • XHTML: A stricter, XML-based version of HTML. It requires lowercase tags, proper nesting, closed elements, and quoted attribute values.
  • Meta Tags: Provide document information inside the head section, such as charset, viewport, description, author, and refresh.
<audio controls>
    <source src="audio.mp3" type="audio/mpeg">
</audio>

<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
