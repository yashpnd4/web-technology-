BASICS OF HTML

Core Concepts, Elements, Attributes Document Structure

1. What is an HTML Element?

An HTML element is defined by a starting tag, some content, and an ending tag:

<tagname> Content goes here... </tagname>

Example: <p>Welcome to my Website</p>

Common Element Examples:

  • <h1>Heading Text</h1> — Main heading
  • <p>Paragraph text</p> — Standard text paragraph
  • <br> — Line break (empty tag, does not need a closing tag)
  • It is bold text — <b>bold text</b>
  • This one is in italic text — <i>italic text</i>
  • This one is underlined text — <u>underlined text</u>
  • THIS ONE IS IN BOLD, ITALIC AND UNDERLINED TEXT. — <b><i><u>combined formatting</u></i></b>
  • I am emphasized text (a little bit stronger than normal) — <em>emphasized text</em>

2. Web Browser & HTML Page Structure

Web Browser:

  • Core Purpose: A web browser is a software application used to access, retrieve, and display content on the World Wide Web.
  • Rendering Mechanism: A browser does not display the raw HTML tags themselves; instead, it interprets the tags as instructions to lay out and present the page content visually.

HTML Page Structure:

  • <head>: Contains page metadata, character encoding, title, scripts, and links to stylesheets.
  • <title>: Defines the title of the webpage shown in the browser's tab or title bar.
  • <body>: The visible portion of the document where all visible content is written (text, images, tables, lists, audio, video, etc.).

3. Essential HTML Rules, Elements & Attributes

  1. HTML Documents: All HTML documents must start with a document type declaration: <!DOCTYPE html>. The HTML document itself begins with <html> and ends with </html>. The <head> tag contains metadata and the <title> of the page. The visible part of the webpage is placed between <body> and </body>.

  2. DOCTYPE Declaration: Represents the document type and helps web browsers render and display pages correctly. It must be written once at the very top of the page. It is not case-sensitive: <!DOCTYPE html>.

  3. HTML Headings: Headings range from <h1> to <h6>:
    <h1>Heading 1</h1>, <h2>Heading 2</h2>, <h3>Heading 3</h3>, <h4>Heading 4</h4>, <h5>Heading 5</h5>, <h6>Heading 6</h6>.

  4. HTML Paragraphs: Defined with the <p> tag. Paragraphs automatically begin on a new line and browsers add space before and after them.

  5. HTML Links: Links are defined by the <a> tag and the destination URL is specified in the href attribute: <a href="https://example.com">Visit Site</a>. Attributes provide additional information about HTML elements.

  6. HTML Images: Images are defined by the <img> tag. Attributes like src (source), alt (alternative text), width, and height configure image properties.

  7. HTML Elements: An HTML element includes everything from the start tag to the end tag. Syntax: <tagname>content</tagname>. Some elements have no content and no end tag, like <br> and <hr>; these are called empty tags (or void elements).

  8. Nested HTML Elements: "Nested" means HTML elements that contain other elements inside them. All HTML documents consist of nested elements that form the document tree.
    Example: The <html> element is the root element; it contains <body>, which in turn contains headings, paragraphs, and lists.

  9. Never Skip the End Tag: Some HTML elements may still display in browsers even if you forget the closing tag because browsers attempt automatic error correction. However, skipping end tags can cause unexpected layout bugs, broken formatting, and validation issues. Always write closing tags!

  10. Empty Tags: Elements with no content and no closing tag are called empty elements. Examples: <br> (line break), <hr> (horizontal rule), and <img> (image).

  11. HTML Is Case-Insensitive: HTML tags are not case-sensitive: <P> and <p> mean the same thing. However, modern W3C standards and XHTML specifications strictly recommend using lowercase for clean, professional code.

  12. HTML Attributes: Attributes provide additional settings and info for HTML elements. They are always specified in the opening tag, usually as name="value" pairs.
    Example: <img src="flower.jpg" alt="Flower Photo">

  13. href Attribute: Used with <a> tags to specify the hyperlink's destination address.

  14. align Attribute: Used to align elements or text on the webpage (e.g., <h1 align="center">Welcome</h1>). In modern web design, CSS text-align is preferred.

  15. width & height Attributes: Specify the dimensions (in pixels or percentages) of elements like images or table cells.

  16. src Attribute: Specifies the file path or web address of an image or media resource (e.g., <img src="img_girl.jpg">).

  17. alt Attribute: Provides alternative text for an image if it cannot be loaded, and assists visually impaired users using screen readers (e.g., <img src="img_girl.jpg" alt="Girl in a dress">).

  18. style Attribute: Used to add inline CSS styling to any HTML element, defining colors, fonts, borders, or sizes.

  19. lang Attribute: Declares the language of the document or element. For example: lang="en" for English, lang="ar" for Arabic, lang="ur" for Urdu.

  20. title Attribute: Provides extra advisory information, usually displayed as a tooltip when hovering over the element (e.g., <p title="Tooltip text">Hover me</p>).

  21. Always Quote Attributes: Attribute values should always be enclosed inside quotes (e.g., title="hello"). While both single and double quotes are supported, double quotes are standard practice.

  22. Heading Hierarchy: Headings range from <h1> down to <h6>. <h1> defines the most important primary topic, while <h6> defines the least important sub-heading.

4. Importance of Headings

Point Explanation
Structure Headings organize the page into clear, logical sections.
Readability Users can easily scan and understand the content.
SEO Search engines use headings to index the structure and topics of the webpage.
Hierarchy Use <h1> for the main topic, <h2> for major sections, and <h3> for sub-sections.

Example Heading Hierarchy

<h1>Travel Guide</h1>
  <h2>Europe</h2>
    <h3>France</h3>
    <h3>Italy</h3>
  <h2>Asia</h2>
    <h3>India</h3>
    <h3>Thailand</h3>

5. Bigger & Custom Headings

Property Explanation
Default Size Browsers assign default font sizes to each heading level (h1 to h6).
Custom Size Heading size can be customized using the style attribute.
CSS Property font-size (e.g., font-size: 60px;)

Basic Example with Custom Size

<h1 style="font-size: 60px;">
    Custom Large Heading
</h1>

6. HTML Paragraphs

Point Explanation
Tag <p> ... </p>
Purpose Defines a block paragraph of text.
Display Paragraphs are block elements; they always start on a new line.
Spacing Browsers automatically add margin/space before and after paragraphs.

Paragraph Example

<p>This is the first paragraph.</p>
<p>This is another paragraph.</p>
