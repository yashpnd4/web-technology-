1. HTML Lists

HTML lists are used to group related items in a clean and organized way.

Unordered List (<ul>)

An unordered list shows items with bullet points. The order of the items does not matter.

  • Coffee
  • Tea
  • Milk

Ordered List (<ol>)

An ordered list displays items numbered sequentially. The order of the items matters.

  1. Coffee
  2. Tea
  3. Milk

Description List (<dl>)

A description list is a list of terms, with a description of each term.

Coffee
Black hot drink
Milk
White cold drink

HTML List Tags Summary

Tag Use & Description
<ul> Creates an unordered (bulleted) list.
<ol> Creates an ordered (numbered) list.
<li> Defines a single list item inside <ul> or <ol>.
<dl> Creates a description list container.
<dt> Defines a term/name in a description list.
<dd> Defines the description for each term in a description list.

2. HTML Tables

HTML tables allow web developers to arrange structured data (text, images, links) into rows and columns.

Basic Table Structure Tags

Tag Use & Description
<table> Defines the complete HTML table container.
<tr> Defines a horizontal row of cells in a table.
<td> Defines a standard data cell (regular text, left-aligned by default).
<th> Defines a table header cell (bold text, centered by default).

Key Concepts of Tables:

  • Table Rows (<tr>): Each row contains one or more data or header cells. A table can have any number of rows.
  • Table Cells (<td>): "td" stands for Table Data. Everything inside a table cell is treated as content (text, links, images, or nested tables).
  • Table Headers (<th>): "th" stands for Table Header. Header text is bold and centered by default. Commonly placed in the first row or first column.

Example Table with Headers

Person 1 Person 2
Emil Tobias

Complete HTML Table Tags Reference

Tag Use & Description
<table> Defines a table container.
<tr> Defines a table row.
<th> Defines a header cell in a table.
<td> Defines a standard data cell in a table.
<caption> Defines a visible caption / title for the table.
<colgroup> Specifies a group of one or more columns in a table for formatting.
<col> Specifies column properties for each column inside a <colgroup>.
<thead> Groups the header content in a table.
<tbody> Groups the main body content in a table.
<tfoot> Groups the footer content in a table.

3. HTML Images

HTML images are used to embed pictures, diagrams, and visual illustrations into a web page to enhance design and readability.

The <img> Element

The <img> tag is used to embed an image into an HTML page. Images are not technically inserted into a webpage; images are linked to web pages. The <img> tag is an empty tag (void element), meaning it has no closing tag.

Core Image Attributes

Attribute Use & Description
src Specifies the path or URL of the image file (source address).
alt Provides alternative text shown if the image cannot load, and assists screen readers.
width Specifies the width of the image (in pixels or percentage).
height Specifies the height of the image (in pixels or percentage).

Important Image Guidelines:

  • src Attribute: Specifies the exact location of the file. Keeping image files organized prevents broken image links.
  • alt Attribute: Shown when an image cannot load, helps visually impaired users with screen readers, and assists search engines in indexing images.
  • width & height: Always specify width and height to reserve space on the page and prevent layout shifting while the page loads.
  • Image as a Link: Place the <img> tag inside an anchor <a href="..."> element to turn the entire image into a clickable link.

Common Web Image Formats

Format Full Form File Extension
APNG Animated Portable Network Graphics .apng
GIF Graphics Interchange Format .gif
ICO Microsoft Icon Format .ico, .cur
JPEG / JPG Joint Photographic Experts Group .jpg, .jpeg, .jfif, .pjp
PNG Portable Network Graphics .png
SVG Scalable Vector Graphics .svg

HTML Image Tags Reference

Tag Use & Description
<img> Embeds an image into the document.
<map> Defines a client-side image map with clickable active areas.
<area> Defines a clickable region inside an image map.
<picture> Defines a responsive container holding multiple image sources for different screen sizes.

4. HTML Forms

An HTML form is used to collect user inputs such as text, selections, passwords, and choices. The collected information is submitted to a web server for processing.

The <form> Element

The <form> element is the container that wraps different interactive form controls like input fields, radio buttons, checkboxes, and buttons.

Common Form <input> Types

Input Type Use & Description
type="text" Creates a single-line text input field for basic user text input.
type="radio" Creates a radio button allowing the user to select only ONE option from a group.
type="checkbox" Creates a checkbox allowing the user to select zero, one, or multiple options.
type="submit" Creates a submit button to send the form data to the server.

Detailed Form Controls:

  • Text Fields: Defined by <input type="text">. Default field width is usually 20 characters.
  • The <label> Element: Gives a descriptive label to an input. Screen readers read labels when inputs are focused. Clicking the label text focuses or toggles the associated input (using matching for and id attributes).
  • Radio Buttons: Used when only one choice is allowed from a set. All radio buttons in the same group must share the exact same name attribute.
  • Checkboxes: Used when multiple options can be chosen independently. Selecting one checkbox does not clear the others.
  • The Submit Button: Defined by <input type="submit">. When clicked, it bundles the form values and sends them to the URL defined in the form's action attribute.
