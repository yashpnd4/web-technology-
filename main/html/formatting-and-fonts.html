FORMATS AND FONTS OF HTML

HTML DISPLAY

There is a common challenge when accessing a website in either full screen or half screen: we are not always sure how the browser will display the texts, images, audio, and layout.

  • Space Collapsing: Adding extra spaces in the HTML code is directly removed by the browser and shown normally. Browsers automatically collapse multiple spaces into a single space.
  • Discarding Line Breaks: The browser automatically ignores extra line breaks when rendering the webpage.
  • <hr> Tag: Helps to create a thematic break in a page. It is a self-closing tag or empty tag, meaning it has no companion end tag.
  • <br> Tag: With the help of the <br> tag, we can manually break a paragraph and move to the next line.
  • <pre> Tag: By using the <pre> tag, we can preserve both the spaces and manual line breaks exactly as they are written in the source code.

HTML STYLES

The HTML style attribute allows us to apply CSS styling directly in the code to enhance visibility and improve user experience on the webpage.

  • Background Color: The CSS background-color property defines background color for HTML elements. CSS background mainly targets elements inside the <body> tag like headings, paragraphs, and tables.
    Example: style="background-color:powderblue;" — This is the basic form to add colors to the background.
  • Text Color: By using style="color:red;" on <h1> and <p>, we can change the text color.
  • Font Family: style="font-family:verdana;" — This is how we can apply different fonts to the text line (e.g., <h1 style="font-family:verdana;">This is a heading</h1>).
  • Font Size: style="font-size:300%;" — This is how we can change the sizes of the text. 300% is three times bigger than the normal text.
  • Text Alignment: style="text-align:center;" — This is how we can change the alignment of the text (left, center, right).
  • Font Style: style="font-style:italic;" — This is how we can change the font style to italic.

TEXT FORMATTING TAGS OVERVIEW

  • <b>: Used to make text bold.
  • <strong>: Used to indicate strong importance. It displays visually bold like <b>, but indicates serious importance.
  • <i>: Used for making text italic.
  • <em>: Used to emphasize text. It displays visually italic like <i>, but indicates semantic emphasis and importance.
  • <mark>: Used to mark or highlight text in a paragraph.
  • <small>: Used to make text smaller in the same paragraph.
  • <del>: Used to delete text, appearing as a single horizontal line through the text.
  • <ins>: Used for inserted text, normally used alongside the <del> tag. It underlines the words.
  • <sub>: Used to make words or letters appear in subscript form (a bit lower). Example: H2O
  • <sup>: Used to make words or letters appear in superscript form (a bit higher). Example: x2

Here cite is an attribute that specifies the URL of the source.
<q> Defines a short inline quotation. It automatically adds quotation marks around the text. Both <blockquote> and <q> are used for quotes.

<address> Indicates contact information for the author or owner of the document:
