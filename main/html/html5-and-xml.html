XML & HTML5 NEW ELEMENTS

1. Introduction to XML

XML stands for eXtensible Markup Language. It is a markup language created for storing and transporting data across different systems. XML is designed to be both human-readable and machine-readable, providing a flexible and self-describing way to structure data.

Example of XML Data Structure

<note>
    <to>Tove</to>
    <from>Jani</from>
    <heading>Reminder</heading>
    <body>Don't forget me this weekend!</body>
</note>

NOTE: XML is strictly case-sensitive. All open tags must be closed properly.

The 7 Core Rules of XML

  1. Root Element: All XML documents must contain one single root element that encloses all other elements.
  2. Closing Tags: In XML, every element must have a corresponding closing tag.
  3. Case Sensitivity: XML tags are strictly case-sensitive.
  4. Quoted Attribute Values: All attribute values must always be enclosed in quotes.
  5. Element Attributes: Elements can contain attributes to provide metadata.
  6. Nested Elements: Elements must be properly nested in a clean hierarchy.
  7. Hierarchical Document Structure: Documents must follow a well-formed tree structure.

2. HTML5 Elements

HTML5 introduced semantic elements that clearly describe their purpose to both browsers and developers. Before HTML5, developers commonly used generic <div> containers with custom IDs or classes.

Element Tag Use & Description
<header> Defines introductory content or a container for navigational links (typically at the top of a page/section).
<nav> Defines a set of major navigation links or menus.
<main> Specifies the primary, central content unique to the document (should only be used once per page).
<article> Defines an independent, self-contained piece of content (blog posts, news stories, forum comments).
<section> Defines a thematic grouping of content, typically with a heading (chapters, tabs, sections).
<aside> Defines content tangentially related to the main content (sidebars, pull quotes, callout boxes).
<footer> Defines a footer for a document or section (copyright, author info, back-to-top links).
<mark> Highlights or marks text for reference purposes.
<time> Defines a machine-readable date, time, or duration.

Benefits of Semantic Elements:

  • SEO (Search Engine Optimization): Helps search engines index and rank the page by understanding its layout and content.
  • Accessibility: Screen readers can navigate directly through headers, navigation bars, and articles.
  • Code Readability: Makes HTML source code cleaner, standard, and easy to maintain.

3. HTML5 Multimedia (Audio & Video)

HTML5 provides native, standardized support for multimedia playback directly inside web browsers without requiring external plugins like Adobe Flash.

Multimedia Benefits:

  • Standardized Playback: Media runs uniformly across all modern browsers and mobile devices.
  • No Third-Party Plugins: Eliminates security and performance issues associated with browser plugins.
  • Direct Page Embedding: Media elements can be styled and scripted like any other HTML tag.

Media Elements:

  • <video>: Used to embed video clips directly on the webpage.
  • <audio>: Used to embed sound files (supports MP3, WAV, OGG formats).

Audio & Video Attributes

Attribute Use & Description
controls Displays standard playback controls (play, pause, volume, seeking, fullscreen).
autoplay Automatically starts playing the audio or video as soon as it is ready.
loop Automatically replays the media file from the beginning once finished.
muted Sets the audio output of the media to be muted by default.

4. HTML5 Form Input Types

HTML5 introduced smart input types that provide native user interface controls (such as date pickers and color pickers) as well as automatic form validation.

Input Type Use & Description
type="email" Used for email addresses; automatically verifies the presence of an "@" symbol.
type="date" Opens a built-in calendar picker for date selection.
type="color" Opens a native color palette picker to select hex color values.
type="range" Creates a slider control to select an approximate numerical value within a range.
type="number" Restricts input to numbers only, offering step up/down arrow buttons.

5. HTML5 Drag and Drop API

HTML5 allows users to grab elements on the screen and drag them to different drop zones directly in the browser. By default, images, links, and highlighted text selections are draggable. Any other element can be made draggable by adding draggable="true".

Drag Event Use & Description
ondragstart Fires when the user begins dragging an element.
ondragover Specifies where the dragged element is permitted to be dropped.
ondrop Fires when the dragged element is successfully released into a valid drop zone.

6. XHTML & Meta Tags

XHTML (Extensible HyperText Markup Language)

XHTML is a stricter, cleaner, XML-based version of HTML. It combines HTML's syntax with XML's strict formatting standards.

Core Rules of XHTML:

  • Lowercase Tags: All tags and attributes must be written in lowercase letters.
  • Closed Elements: All elements, including empty elements (like <br /> and <hr />), must be properly closed.
  • Proper Nesting: Elements must always be closed in the exact reverse order that they were opened.
  • Quoted Attributes: All attribute values must be enclosed in double quotes.

HTML Meta Tags

Meta tags provide metadata (information about data) to web browsers, search engines, and web servers. They are placed inside the <head> element and do not appear visually on the page.

Meta Tag Attribute Use & Description
charset Defines the character encoding for the HTML document (typically charset="UTF-8").
viewport Sets the initial view area to make pages responsive across mobile, tablet, and desktop screens.
description Provides a concise summary of the page displayed in search engine results (SEO snippet).
author Specifies the name of the author or organization who created the document.
refresh Automatically reloads the page or redirects the visitor after a set number of seconds.
