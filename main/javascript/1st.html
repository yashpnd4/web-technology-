Client-Side Scripting with JavaScript

1. What is JavaScript?

JavaScript is a high-level, dynamic scripting language used to control the behavior of a webpage. It runs in the browser and responds to user actions such as clicks, form submissions, and input changes.

JavaScript can calculate values, make decisions, repeat tasks, change page content, validate forms, and fetch data from a server.

2. JavaScript Building Blocks

  • Values: Data used by a program.
  • Variables: Store values for later use.
  • Operators: Perform calculations and comparisons.
  • Conditions: Make decisions.
  • Loops: Repeat instructions.
  • Functions: Store reusable blocks of code.
  • Objects and Arrays: Organize related data and lists of values.

3. JavaScript Data Types

A data type describes the kind of value stored in a variable. JavaScript is dynamically typed, so a variable can hold different types of values at different times.

Example:

const student = { name: "Asha", score: 85 };

console.log(typeof isEnrolled);
console.log(typeof selectedCourse);

Note: typeof null returns "object" for historical reasons. Arrays also return "object" with typeof. Use Array.isArray(value) to check whether a value is an array. Functions have the typeof result "function".

4. Variables: let and const

A variable stores data so a program can use it later. Use const when the variable should not be reassigned, and let when reassignment is required. 

const studentName = "Asha";
let marks = 78;
let isPass = marks >= 40;

console.log(studentName);
console.log(marks);
console.log(isPass);

marks = marks + 7;
console.log(marks);

5. Operators and Conditions

Operators perform operations on values. Arithmetic operators include +, -, *, and /. Comparison operators compare values. Logical operators combine conditions.

  • && - AND: true when both conditions are true.
  • || - OR: true when at least one condition is true.
  • ! - NOT: reverses a Boolean value.

The if, else if, and else statements are used to make decisions. The ternary operator is a shorter way to choose between two values. 

const age = 20;
const feesPaid = true;

if (age >= 18 && feesPaid) {
    console.log("Student can register");
} else if (age >= 18 && !feesPaid) {
    console.log("Please pay the fees");
} else {
    console.log("Student is not eligible");
}

const result = (age >= 18) ? "Adult" : "Minor";
console.log(result);

6. Loops

Loops repeat a block of instructions until a condition is met. They are useful for processing lists and repeating tasks.

  • for: Repeats code using an initialization, condition, and update.
  • while: Repeats code while a condition is true.
  • for...of: Visits each value in an iterable such as an array.
const subjects = ["HTML", "CSS", "JavaScript"];

for (let i = 0; i < subjects.length; i++) {
    console.log(subjects[i]);
}

for (const subject of subjects) {
    console.log(subject);
}

let count = 1;
while (count <= 3) {
    console.log(count);
    count++;
}

7. Functions

A function is a reusable block of code. It can receive values through parameters and return a result. Functions reduce repeated code and make programs easier to maintain. 

function calculateTotal(price, quantity) {
    return price * quantity;
}

const bill = calculateTotal(120, 3);
console.log(bill);

function greet(student) {
    return "Welcome, " + student + "!";
}

console.log(greet("Asha"));

8. Popup Boxes

Browsers provide three common popup functions:

  • alert(): Shows a message to the user.
  • confirm(): Asks for an OK or Cancel decision and returns true or false.
  • prompt(): Asks the user to enter a short text value.
alert("Welcome to the Web Technologies lab!");

const proceed = confirm("Do you want to continue?");

if (proceed) {
    console.log("User clicked OK");
} else {
    console.log("User clicked Cancel");
}

const name = prompt("Enter your name:");
console.log("Hello, " + name);

Popup boxes are useful for simple demonstrations. In real applications, developers often use custom page elements instead of relying on browser dialogs.

9. Important Points

  • JavaScript adds behavior to a webpage.
  • Use let for values that may be reassigned and const for bindings that should not be reassigned.
  • JavaScript includes primitive data types and objects.
  • Conditions make decisions and loops repeat tasks.
  • Functions make code reusable.
  • alert(), confirm(), and prompt() are browser popup functions.
