DHTML: HTML, CSS, and JavaScript Together

1. What is DHTML?

DHTML stands for Dynamic HTML. It describes the use of HTML, CSS, and JavaScript together to make a webpage respond to changes and user actions.

DHTML is not a separate programming language. HTML provides the structure, CSS controls the appearance, and JavaScript updates the page using the DOM and browser events.

2. Three Technologies Used in DHTML

Technology Purpose
HTML Creates elements and content such as headings, cards, forms, and buttons.
CSS Defines layout, colors, spacing, and visual states.
JavaScript Listens for events, makes decisions, and updates DOM content, attributes, or classes.

3. How a DHTML Interaction Works

  1. The browser reads HTML and creates a DOM tree of elements.
  2. The browser applies CSS rules to decide how the elements look.
  3. JavaScript finds the required elements and registers an event listener.
  4. When an event occurs, JavaScript updates the DOM or changes a class.
  5. The browser applies the changed styles and displays the updated result.

4. Example: HTML Creates the Elements

<div class="dhtml-card" id="dhtml-card">
    <h3>Interactive Course Card</h3>
    <p>Press the button to highlight this card.</p>
</div>

<button type="button" id="dhtml-toggle">
    Toggle Highlight
</button>

5. CSS Defines the Visual State

.dhtml-card {
    padding: 16px;
    background: #f1f5f5;
}

.dhtml-card.is-active {
    color: white;
    background: #087e78;
}

6. JavaScript Changes the State

const card = document.querySelector("#dhtml-card");
const toggleButton = document.querySelector("#dhtml-toggle");

toggleButton.addEventListener("click", () => {
    card.classList.toggle("is-active");
});

When the button is clicked, JavaScript adds or removes the is-active class. CSS then applies the matching visual rules to the card.

7. Important Points

  • DHTML means Dynamic HTML.
  • DHTML is not a separate programming language.
  • HTML provides structure, CSS provides presentation, and JavaScript provides behavior.
  • The DOM allows JavaScript to update webpage elements.
  • Using classList keeps visual styling separate from JavaScript logic.
  • Use semantic HTML controls such as a real button for keyboard accessibility.
