1. What is jQuery?

jQuery is a JavaScript library that provides shorter methods for selecting HTML elements, handling events, changing the DOM, creating effects, and making AJAX requests.

jQuery was especially useful when browser differences required extra compatibility work. Modern browsers provide many equivalent features directly through JavaScript, but jQuery is still found in existing and older projects.

2. Advantages of jQuery

  • Uses CSS-style selectors to select HTML elements.
  • Provides short methods for changing content and classes.
  • Makes event handling easier to write.
  • Provides methods for effects and AJAX requests.
  • Uses method chaining to perform multiple operations on selected elements.

3. Common jQuery Methods

Method Purpose
$()Selects elements using CSS-style selectors.
$(function(){ ... })Runs code when the document is ready.
.on()Attaches an event handler.
.text()Reads or changes text content.
.addClass()Adds a CSS class.
.removeClass()Removes a CSS class.
.toggleClass()Adds a class if absent or removes it if present.

4. JavaScript and jQuery Comparison

Task Vanilla JavaScript jQuery
Select an element document.querySelector("#message") $("#message")
Listen for a click element.addEventListener("click", handler) $(element).on("click", handler)
Set text element.textContent = "Hello" $(element).text("Hello")
Toggle a class element.classList.toggle("active") $(element).toggleClass("active")

5. jQuery Example

In this example, jQuery waits for the document to be ready, listens for a button click, changes the message text, and toggles a CSS class. 

$(function () {
    $("#jquery-button").on("click", function () {
        $("#jquery-message")
            .text("Updated by a jQuery event handler.")
            .toggleClass("is-highlighted");
    });
});

6. jQuery Dependency

jQuery is a library, so it must be included in a project before its methods can run. The examples in these notes explain the syntax; they do not load jQuery automatically.

A student should learn JavaScript and the DOM first. jQuery becomes easier to understand after the browser object model is familiar.

7. Important Points

  • jQuery is a JavaScript library, not a separate programming language.
  • It uses CSS-style selectors such as $("#message").
  • The on() method attaches event handlers.
  • The text() method changes text content.
  • addClass(), removeClass(), and toggleClass() change CSS classes.
  • jQuery must be included before its methods can be used.
  • Modern JavaScript has native alternatives for many jQuery tasks.
