Basic JavaScript and jQuery Questions and Answers

These questions are based on Unit 4: JavaScript and jQuery. They cover JavaScript basics, data types, objects, the DOM, forms, DHTML, events, AJAX, Fetch, and jQuery.

1. What is JavaScript? How is it different from HTML and CSS?

Answer: JavaScript is a high-level, dynamic scripting language used to control the behavior of a webpage.

  • HTML: Provides webpage structure and content.
  • CSS: Controls webpage appearance.
  • JavaScript: Adds behavior and interactivity.

2. What are variables in JavaScript? Explain let and const.

Answer: Variables store data for later use. Use let when a value may be reassigned and const when the variable binding should not be reassigned.

const studentName = "Asha";
let marks = 78;
marks = marks + 7;

console.log(studentName);
console.log(marks);

3. What are the data types in JavaScript?

Answer: Primitive data types are String, Number, BigInt, Boolean, Undefined, Null, and Symbol. Object is a non-primitive type. Arrays and functions are also object types.

const name = "Asha";
const score = 85;
const passed = true;
let selectedCourse;
const missingValue = null;
const subjects = ["HTML", "CSS"];
const student = { name: "Asha" };

console.log(typeof name);
console.log(Array.isArray(subjects));

4. What are operators and conditional statements?

Answer: Operators perform calculations and comparisons. Arithmetic operators include +, -, *, and /. Comparison operators include >, <, ===, and !==. Logical operators include && (AND), || (OR), and ! (NOT).

Conditional statements such as if, else if, and else make decisions based on conditions.

const age = 20;

if (age >= 18) {
    console.log("Adult");
} else {
    console.log("Minor");
}

5. What are loops in JavaScript? Name their types.

Answer: Loops repeat instructions. Common types in the unit are for, while, and for...of.

const subjects = ["HTML", "CSS", "JavaScript"];

for (const subject of subjects) {
    console.log(subject);
}

6. What is a function? Explain parameters and return values.

Answer: A function is a reusable block of code. Parameters receive values, and return sends a result back.

function calculateTotal(price, quantity) {
    return price * quantity;
}

console.log(calculateTotal(120, 3));

7. What are JavaScript popup boxes?

Answer:

  • alert(): Displays a message.
  • confirm(): Asks the user to choose OK or Cancel and returns true or false.
  • prompt(): Asks the user to enter a short text value.

8. What is a JavaScript object? What is an array?

Answer: An object stores related properties and methods. An array stores multiple values in an ordered list.

const learner = {
    name: "Asha",
    unit: 4
};

const subjects = ["HTML", "CSS"];

console.log(learner.name);
console.log(subjects[0]);

9. What is the DOM? Explain common DOM operations.

Answer: DOM stands for Document Object Model. It represents an HTML document as a tree of nodes and allows JavaScript to select and update page elements.

  • document.querySelector() - Selects an element.
  • textContent - Reads or changes text.
  • classList.toggle() - Adds or removes a class.
  • document.createElement() - Creates a new element.
  • append() - Adds content to an element.

10. What is form validation? Name common validation attributes and methods.

Answer: Form validation checks user input before it is accepted or submitted.

  • HTML attributes: required, type, minlength, maxlength, min, max, step, and pattern.
  • JavaScript methods: checkValidity(), reportValidity(), validity, and setCustomValidity().

Client-side validation improves user feedback, but submitted data must also be checked on the server.

11. What is DHTML?

Answer: DHTML stands for Dynamic HTML. It describes the use of HTML, CSS, and JavaScript together to make webpages respond to user actions. It is not a separate programming language.

  • HTML provides structure.
  • CSS provides presentation.
  • JavaScript provides behavior and updates the DOM.

12. What are JavaScript events? What is addEventListener()?

Answer: Events are browser occurrences such as clicks, input changes, and form submissions. addEventListener() connects an event to a function.

const button = document.querySelector("#myButton");

button.addEventListener("click", (event) => {
    console.log("Button clicked");
    console.log(event.currentTarget);
});

13. What is AJAX? Explain its request-response cycle.

Answer: AJAX stands for Asynchronous JavaScript and XML. It sends HTTP requests using JavaScript and updates part of a webpage without loading a new document. JSON is a common response format today.

  1. A user action starts a request.
  2. The browser sends a GET or POST request.
  3. The server sends a response.
  4. JavaScript reads the response and updates the DOM.

14. What is Fetch API? Explain Promise, async, await, and CORS.

Answer: Fetch is a browser API for making HTTP requests. It returns a Promise. async and await make asynchronous code easier to write. CORS stands for Cross-Origin Resource Sharing and controls whether a page can read a response from a different origin.

async function loadData() {
    try {
        const response = await fetch("/api/courses");

        if (!response.ok) {
            throw new Error("HTTP error: " + response.status);
        }

        const data = await response.json();
        console.log(data);
    } catch (error) {
        console.error(error);
    }
}

15. What is jQuery? Name some common jQuery methods.

Answer: jQuery is a JavaScript library that simplifies selecting elements, handling events, changing the DOM, effects, and AJAX.

  • $() - Selects elements.
  • .on() - Attaches an event handler.
  • .text() - Reads or changes text.
  • .addClass() - Adds a CSS class.
  • .removeClass() - Removes a CSS class.
  • .toggleClass() - Adds or removes a CSS class.
$(function () {
    $("#myButton").on("click", function () {
        $("#message").text("Updated by jQuery.");
    });
});
