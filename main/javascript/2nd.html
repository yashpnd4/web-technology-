JavaScript Objects and the DOM

← Back to JavaScript Overview

1. What is an Object?

An object is a collection of related data and behavior. It stores information using properties and can contain functions called methods. For example, a student object can contain a name, unit, and a method to display information. 

const learner = {
    name: "Asha",
    unit: 4,
    introduce() {
        return this.name + " is studying Unit " + this.unit;
    }
};

console.log(learner.name);
console.log(learner.introduce());
  • Property: A value stored in an object, such as name or unit.
  • Method: A function stored in or associated with an object.
  • this: Refers to the object in a method call such as learner.introduce().

2. What is the DOM?

DOM stands for Document Object Model. It represents an HTML document as a tree of nodes. The browser creates the DOM when it reads the HTML document. JavaScript can use the DOM to find elements, read their content, change attributes and classes, and create new elements.

The DOM allows a webpage to change without reloading the whole document. For example, JavaScript can change a heading, update a button label, add an item to a list, or highlight a card.

3. Common DOM Operations

Operation Example Use
Select an element document.querySelector(".notice") Finds the first element matching a CSS selector.
Read or set text element.textContent = "Updated" Changes the text inside an element.
Change a class element.classList.toggle("active") Adds or removes a class.
Create and add an element list.append(newItem) Creates or adds content to the page.

4. Selecting an HTML Element

JavaScript can select an element using its ID, class, tag name, or another CSS selector. 

const message = document.querySelector("#message");
message.textContent = "Welcome to JavaScript!";

document.querySelector() returns the first matching element. If no element matches, it returns null.

5. Changing Text and Classes

The textContent property changes the text inside an element. The classList methods can add, remove, or toggle CSS classes. 

const message = document.querySelector("#message");
message.textContent = "The text has been changed.";

const card = document.querySelector(".card");
card.classList.add("active");
card.classList.remove("active");
card.classList.toggle("active");

6. Creating and Adding Elements

JavaScript can create a new HTML element and add it to an existing element in the DOM. 

const newItem = document.createElement("li");
newItem.textContent = "JavaScript";

const subjectList = document.querySelector("#subjects");
subjectList.append(newItem);

7. Important Points

  • Objects group related properties and methods.
  • The DOM represents an HTML page as a tree of nodes.
  • JavaScript can select HTML elements and change their content.
  • textContent changes text without parsing it as HTML.
  • classList can add, remove, or toggle CSS classes.
  • JavaScript can create and append new elements.
