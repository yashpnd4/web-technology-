Forms and Validation

1. What is Form Validation?

Form validation checks the information entered by a user before an application accepts or sends it. It helps find empty fields, invalid email addresses, short passwords, and other incorrect values.

Validation guides the user, reduces input mistakes, and helps prevent invalid data from being submitted.

2. HTML Validation Attributes

HTML provides built-in validation attributes. These rules can be checked by the browser when a form is submitted.

Attribute Example Purpose
required <input required> A value must be entered or selected.
type <input type="email"> Uses an input type suited to the data and checks basic formats.
minlength / maxlength minlength="2" maxlength="40" Sets minimum and maximum text length.
min / max / step min="1" max="10" step="1" Limits numeric or date values and permitted increments.
pattern pattern="[A-Z]{2}[0-9]{4}" Requires text to match a regular-expression pattern.

Example of HTML Form Validation:

<form>
    <label for="email">Email:</label>
    <input type="email" id="email" required>

    <label for="password">Password:</label>
    <input type="password" id="password"
           minlength="8" required>

    <input type="submit" value="Submit">
</form>

3. JavaScript Validation

JavaScript can add checks that are specific to an application. It can display custom error messages, check values, and guide users to correct mistakes.

Common browser validation methods are:

  • checkValidity(): Returns true when the element or form passes its validation rules.
  • reportValidity(): Asks the browser to display its validation feedback.
  • validity: Provides details about the validation state.
  • setCustomValidity(message): Sets a custom error message. Use an empty string to clear the error.

Example:

const form = document.querySelector("#myForm");

form.addEventListener("submit", (event) => {
    event.preventDefault();

    if (!form.checkValidity()) {
        form.reportValidity();
        return;
    }

    console.log("Form is ready to submit.");
});

event.preventDefault() prevents the browser's default form submission so JavaScript can check the values first.

4. Validation Process

  1. Collect the values when the user submits the form.
  2. Check basic constraints such as required fields and input types.
  3. Apply additional application-specific rules.
  4. Show clear feedback so the user can correct errors.
  5. Continue with submission only after validation passes.
  6. Validate the submitted data again on the server.

5. Important Security Point

Client-side validation improves user experience, but it is not a security boundary. A user can disable JavaScript or send data directly to a server. Therefore, the server must validate submitted data too.

6. Important Points

  • Form validation checks user input before accepting or sending it.
  • HTML attributes provide basic validation rules.
  • JavaScript can add custom checks and messages.
  • checkValidity() checks whether constraints pass.
  • reportValidity() displays browser validation feedback.
  • Always validate submitted data on the server.
