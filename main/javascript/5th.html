JavaScript Events and Buttons

1. What is an Event?

An event is something that happens in the browser, such as a click, key press, input change, form submission, or page load. JavaScript can listen for events and run a function when they occur.

2. Common JavaScript Events

Event Purpose
click Occurs when an element, such as a button, is activated.
input Occurs when a user edits an input value.
submit Occurs when a form is submitted.

3. Event Listener

An event listener connects an event to a function. The addEventListener() method is commonly used to listen for events. It keeps JavaScript behavior separate from HTML markup.

Syntax:

element.addEventListener("event", function);

Example:

const button = document.querySelector("#myButton");

button.addEventListener("click", (event) => {
    console.log("Button activated");
});

4. The Event Object

When an event occurs, the browser provides an event object. It contains details about the event and the element that received it.

The event.currentTarget property refers to the element on which the event listener is registered. 

button.addEventListener("click", (event) => {
    console.log("Activated:", event.currentTarget);
});

5. Example: Button Counter

A button can be used to increase a counter. JavaScript listens for each click and updates the displayed number. 

let count = 0;

const button = document.querySelector("#addButton");
const output = document.querySelector("#count");

button.addEventListener("click", () => {
    count = count + 1;
    output.textContent = count;
});

6. Why Use addEventListener()?

  • Keeps JavaScript behavior separate from HTML structure.
  • Allows multiple listeners to be attached to an element.
  • Provides access to the event object.
  • Makes code easier to read and maintain.

7. Important Points

  • An event is an action or occurrence in the browser.
  • click, input, and submit are common events.
  • addEventListener() connects an event to a function.
  • The event object contains information about the event.
  • Native buttons can be activated using a mouse or keyboard.
