Difference Between Internet and World Wide Web

← Back to WWW Overview

Overview

Many people use the terms Internet and World Wide Web interchangeably, but they are not the same thing. The Internet is the underlying physical network, while the World Wide Web is a service that runs on top of it.

Comparison Table

Feature Internet World Wide Web (WWW)
Definition A global network of interconnected computer networks operating on TCP/IP protocols. A collection of interlinked multimedia documents accessed through the Internet using HTTP.
Origin Originated as ARPANET in the late 1960s (1969). Invented in 1989 by Sir Tim Berners-Lee at CERN.
Nature Hardware-based infrastructure (routers, servers, cables, satellites). Software-based information system running on top of the Internet.
Protocols TCP, IP, UDP, FTP, SMTP, DNS, etc. HTTP, HTTPS, HTML.
Scope The broader system; includes email, file sharing, gaming, and the Web. A specific subset/service of the Internet.
