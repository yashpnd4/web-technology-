Difference Between IP Address and MAC Address

← Back to WWW Overview

Overview

Every connected device uses two addresses to communicate over a computer network: an IP address for routing traffic across different networks, and a MAC address for identifying the hardware device on the local network.

Comparison Table

Feature IP Address (Logical Address) MAC Address (Physical Address)
Full Form Internet Protocol Address Media Access Control Address
Purpose Identifies the connection of a device on a network Identifies the physical hardware of the device itself
Assigned By Internet Service Provider (ISP) or Network Administrator Manufacturer of the Network Interface Card (NIC)
OSI Layer Network Layer (Layer 3) Data Link Layer (Layer 2)
Address Length 32 bits (IPv4) or 128 bits (IPv6) 48 bits (6 bytes)
Format Example 192.168.1.1 00:1A:2B:3C:4D:5E
Modifiability Dynamic; changes when moving across networks Permanent; hardcoded into the hardware chip
