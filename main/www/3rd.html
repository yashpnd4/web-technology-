What is a URL?

URL stands for Uniform Resource Locator.

A URL is the address of a unique resource on the web. It indicates both the location of the resource and the protocol used to access it.

URL Breakdown Example

https://www.bing.com

Component Explanation
https:// Hyper Text Transfer Protocol Secure: Used to transfer encrypted data securely between the server and browser.
www World Wide Web: A subdomain indicating that the resource is hosted on the World Wide Web.
bing Domain Name: The unique, human-readable name of the website that maps to an IP address via DNS.
.com Top-Level Domain (TLD): The last part of a domain name indicating the purpose or category of the organization (commercial).
