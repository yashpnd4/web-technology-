Introduction to WWW History

WWW was created at the CERN laboratory in Geneva, Switzerland in 1989.

It was invented by Tim Berners-Lee and his team of scientists, created to share information with each other at CERN.

The first web page, the first web browser, and the first web server were all created in 1990.

Evolution of the Web

  1. Web 1.0 (1990-2000): Introduced static websites that primarily allowed one-way information sharing.
  2. Web 2.0 (2000-2010): Brought interactive, social platforms enabling user-generated content and global community connection.
  3. Web 3.0 (2010-2020): Focused on the semantic web, allowing machines to understand data and provide deeply personalized experiences.
  4. Web 4.0 (2020-2030): Expected to be a fully intelligent, decentralized ecosystem powered by AI and integrated web operating systems.

Version Timeline Key Features
Web 1.0 1990-2000 Static websites, Read-only content
Web 2.0 2000-2010 Social media, User-generated content, Interactivity
Web 3.0 2010-2020 Semantic web, AI-driven personalization, Decentralization
Web 4.0 2020-2030 (Expected) Intelligent web, Integrated operating systems, Advanced AI

True Facts About the Web

  1. 1.5 Billion+ Active Websites: The internet currently hosts more than 1.5 billion unique websites, and this number grows daily.
  2. Chrome's Massive Dominance: Google Chrome is used by more than 60% of people browsing the web.
  3. Truly Global and Multilingual: The Web officially operates in over 150 diverse languages to connect users worldwide.

Web Browser

A software interface used to access and display hyperlinked resources on the World Wide Web, translating code into accessible multimedia.

Key Functions & Capabilities:

  1. Resource Rendering: Displays text, data, pictures, animation, and video seamlessly.
  2. Multi-tasking Utility: Conducts searches, transfers files, and handles mailing services.
  3. Common Software: Includes popular browsers like Google Chrome, Mozilla Firefox, Opera, and Microsoft Edge.

Client-Server Model

Client: Requests services or resources. Typically a user-facing application like a web browser or mobile app.

Server: Provides services or resources. Handles requests, processes data, and sends responses.

Key Points:

  • Communication happens over a network using defined protocols (like HTTP, TCP/IP).
  • Multiple clients can connect to the same server simultaneously.
  • Common use cases: web applications, email systems, and online games.
