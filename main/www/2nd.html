Introduction to HTTP

HTTP is a protocol used to transfer data from one end to another over the internet.

HTTP stands for Hyper Text Transfer Protocol.

HTTP is an application layer protocol used by web browsers and web servers to communicate.

HTTP Request Commands

To transfer data we use commands such as GET and POST:

Command Purpose
GET Used to retrieve data from the server
POST Used to send data to the server
PUT Used to update existing data on the server
DELETE Used to delete data from the server

URL Format Breakdown:

Example: www.websitename.com

  • www: World Wide Web (subdomain)
  • websitename: The name of the website (domain)
  • .com: The top-level domain extension

Other common extensions: .edu, .org, .net, .in, .uk, .us, .ca, .au, .jp, .cn

HTTP Response Structure

  • Status Line: Contains HTTP status codes, e.g., 200 (OK), 404 (Not Found), 500 (Server Error), 503, 403
  • Headers: Contains meta-information like Content-Type, Set-Cookie, and Cache-Control
  • Body: Contains requested content such as HTML, CSS, JavaScript, images, or JSON data

HTTP Request-Response Cycle

  1. 1. Domain Name Resolution (DNS):
    The browser resolves the domain name (e.g., http://example.com) to an IP address using DNS servers.

  2. 2. TCP 3-Way Handshake:
    Client sends SYN, Server responds with SYN-ACK, Client sends ACK to establish a reliable connection on port 80 (HTTP) or 443 (HTTPS).

  3. 3. HTTP Transmission:
    Client sends the HTTP Request. The server processes the request, performs any necessary database operations, and returns an HTTP Response.

  4. 4. Connection Teardown / Keep-Alive:
    The connection closes or remains open (Keep-Alive) for subsequent requests.
