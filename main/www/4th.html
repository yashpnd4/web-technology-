What is DNS?

DNS stands for Domain Name System.

Computers locate each other using numeric IP addresses (such as 142.250.190.46), but IP addresses are hard for humans to remember. To solve this, DNS acts like an internet phonebook, translating human-friendly names (like www.bing.com) into machine-readable IP addresses.

Two Types of IP Addresses:

  1. Public IP Address: Used to identify devices over the global internet.
  2. Private IP Address: Used inside a local network (like home Wi-Fi).

Top-Level Domains (TLD)

The TLD is the last segment in a domain name (after the last dot).

Domain Type Description & Examples
gTLD (Generic TLD) Used for general purposes across the world.
Examples: .com, .org, .net, .info, .biz, .pro
ccTLD (Country Code TLD) Two-letter domains reserved for a specific country or region.
Examples: .in (India), .us (USA), .uk (United Kingdom), .de (Germany), .jp (Japan)

Restricted Domains

Category Details & Examples
Government DNS Reserved strictly for government bodies and official entities.
Examples: .gov, .mil, .fed, .gob
Educational DNS Reserved specifically for accredited schools, colleges, and universities.
Examples: .edu, .ac, .sch

Labels in DNS

A label is an individual word or segment between dots in a domain name.

  • Length must be between 1 and 63 characters
  • Labels are case-insensitive (e.g., Google.com is the same as google.com)
  • Allowed characters: a-z, 0-9, and hyphen (-)
  • Hyphens are not allowed at the start or end of a label

Second-Level Domain (SLD)

SLD is the domain directly below the TLD. It represents the specific identity of the organization or website.

Domains can have multiple levels. For example, in informatics.ed.ac.uk:

  • .uk: Country Code TLD
  • .ac: Second-level domain (academic)
  • .ed: Third-level domain (Edinburgh)
  • informatics: Subdomain

Buying a Domain Name

Domain names cannot be bought permanently. Instead, you lease or rent them for 1 to 10 years at a time through registrars such as GoDaddy, Namecheap, or Google Domains.
