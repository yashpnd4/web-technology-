Difference Between URL and URI

Overview

URI (Uniform Resource Identifier) is a generic term used to identify any resource by name, location, or both.

URL (Uniform Resource Locator) is a specific type of URI that not only identifies the resource, but also specifies how to reach or locate it via a network protocol.

Rule of thumb: Every URL is a URI, but not every URI is a URL.

Comparison Table

Aspect URI (Uniform Resource Identifier) URL (Uniform Resource Locator)
Primary Purpose To uniquely identify a resource by name or location To identify and provide the access method / location
Protocol Requirement Does not necessarily require a protocol (e.g., URN) Always includes an explicit protocol (http://, ftp://)
Relationship Parent category (umbrella term) Subcategory of URI
Example urn:isbn:0451450523 https://www.google.com
