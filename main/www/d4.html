Difference Between IPv4 and IPv6

← Back to WWW Overview

Overview

IPv4 (Internet Protocol Version 4) was deployed in 1983 and is the foundation of the modern internet. Due to the explosion of internet-connected devices, IPv4 addresses have become scarce, leading to the development of IPv6 (Internet Protocol Version 6).

Comparison Table

Feature IPv4 IPv6
Address Size 32 bits (4 bytes) 128 bits (16 bytes)
Address Format Dotted-decimal notation (e.g., 192.168.1.1) Hexadecimal colon notation (e.g., 2001:0db8::7334)
Address Space ~4.3 billion addresses (232) ~3.4 × 1038 addresses (2128)
Security IPsec is optional / add-on IPsec is built directly into the standard
Header Format Variable length (20 to 60 bytes) with checksum Fixed length (40 bytes) with no checksum
Configuration Manual or DHCP (Dynamic Host Configuration Protocol) Stateless Address Autoconfiguration (SLAAC) or DHCPv6
Transmission Types Unicast, Multicast, Broadcast Unicast, Multicast, Anycast (No Broadcast)
