Basic WWW and Internet Questions

These questions cover the World Wide Web, its history, HTTP, URLs, DNS, IP addresses, networking comparisons, and web designing concepts.

1. What is the World Wide Web (WWW)?

Answer: WWW stands for World Wide Web. It is a system of interconnected web pages and information that can be accessed using the Internet. Users move between pages through hyperlinks.

Key features:

  • Global interaction and information sharing.
  • Navigation through hyperlinks.
  • Support for text, pictures, audio, and video.
  • Access to websites and online services.

2. What is the difference between the Internet and WWW?

Answer:

Uses protocols such as TCP, IP, UDP, FTP, SMTP, and DNS. Uses HTTP, HTTPS, and HTML for web communication and content.

3. Who invented the World Wide Web and how did it develop?

Answer: The WWW was created at the CERN laboratory in Geneva, Switzerland, in 1989. It was invented by Tim Berners-Lee and his team to share information. The first web page, web browser, and web server were created in 1990.

Evolution of the Web:

  • Web 1.0: Mainly static websites and read-only information.
  • Web 2.0: Interactive websites, social platforms, and user-generated content.
  • Web 3.0: Semantic web concepts, personalization, and decentralization.
  • Web 4.0: Described in the notes as an expected intelligent and connected web.

4. What is a web browser and what is a web server?

Answer:

  • Web Browser: Software used by a user to request and display web pages. Examples include Chrome, Firefox, Safari, and Edge.
  • Web Server: Software or hardware that stores, processes, and supplies web pages in response to requests. Examples include Apache, Nginx, and Microsoft IIS.

In the client-server model, the browser acts as the client and the server provides the requested resource.

HTTP and URL Questions

5. What is HTTP? Explain common HTTP request methods.

Answer: HTTP stands for Hypertext Transfer Protocol. It is an application layer protocol used by web browsers and web servers to communicate and transfer data.

Method Purpose
GETRetrieves data from the server.
POSTSends data to the server.
PUTUpdates existing data on the server.
DELETEDeletes data from the server.

6. What are the parts of an HTTP response?

Answer: An HTTP response has three main parts:

  1. Status Line: Contains the HTTP status code, such as 200 (OK), 404 (Not Found), or 500 (Server Error).
  2. Headers: Contain additional information such as Content-Type, Set-Cookie, and Cache-Control.
  3. Body: Contains the requested content, such as HTML, CSS, images, or JSON data.

7. Explain the HTTP request-response cycle.

Answer: The basic request-response cycle has these steps:

  1. DNS Resolution: The browser finds the IP address for the domain name.
  2. TCP Handshake: The client and server establish a connection using SYN, SYN-ACK, and ACK.
  3. HTTP Request: The browser sends a request to the server.
  4. HTTP Response: The server processes the request and sends a response.
  5. Connection: The connection may close or remain open for later requests using Keep-Alive.

8. What is a URL? Explain its parts.

Answer: URL stands for Uniform Resource Locator. It is the address of a resource on the web. It identifies the location of a resource and the protocol used to access it.

Example: https://www.bing.com

  • https:// - Secure protocol used to transfer data.
  • www - Subdomain.
  • bing - Domain name.
  • .com - Top-Level Domain (TLD).

A URI identifies a resource by name or location. A URL is a type of URI that also gives the way or location to access the resource. Every URL is a URI, but not every URI is a URL.

DNS and IP Address Questions

9. What is DNS and why is it needed?

Answer: DNS stands for Domain Name System. It works like an Internet phonebook by translating human-readable domain names, such as www.bing.com, into numerical IP addresses that computers use to locate one another.

10. What are TLD, SLD, and DNS labels?

Answer:

  • TLD: Top-Level Domain. It is the last part of a domain name, such as .com, .org, .net, or .in.
  • gTLD: Generic Top-Level Domain, used for general purposes, such as .com, .org, and .net.
  • ccTLD: Country Code Top-Level Domain, such as .in for India and .uk for the United Kingdom.
  • SLD: Second-Level Domain. It is the domain directly below the TLD.
  • DNS Label: An individual part of a domain name separated by dots.

11. What is an IP address? Explain its types.

Answer: An IP address stands for Internet Protocol address. It is a numerical label assigned to a device on a network so that devices can communicate and data can reach the correct destination.

  • Public IP: Used to identify a device or network on the global Internet.
  • Private IP: Used inside a local network, such as home Wi-Fi.
  • Static IP: A fixed address that normally does not change.
  • Dynamic IP: An address assigned automatically by a DHCP server and may change over time.

13. What are reserved IP addresses and IPv4 address classes?

Answer: Some IP addresses have special purposes:

  • 0.0.0.0 - Default route or non-routable meta-address.
  • 127.0.0.1 - Loopback address, also called localhost.
  • 169.254.0.1 - 169.254.0.254 - APIPA range used when DHCP fails, as listed in the notes.
  • 255.255.255.255 - Broadcast address for the local subnet.

IPv4 address classes: Class A is for very large networks, Class B for medium to large networks, Class C for small networks, Class D for multicast, and Class E for experimental or research use.

14. What are common IP security threats and how can an IP address be protected?

Answer: Common threats mentioned in the notes include:

  • DDoS (Distributed Denial of Service) attacks.
  • Location tracking and IP spoofing.
  • Unauthorized remote access attempts.

Protection methods:

  • Use a VPN to mask the real IP address.
  • Use HTTPS websites.
  • Enable a NAT firewall on the router.
  • Use strong and unique passwords for network hardware.
  • Keep the operating system and router firmware updated.

15. What are the basic principles of good web design?

Answer: Important web design principles include:

  • Visual Hierarchy: Use size, typography, color, and spacing to guide the user's attention.
  • Navigation: Keep menus clear and important information easy to reach.
  • Accessibility: Use image alt text, sufficient text contrast, and keyboard navigation.
  • Responsive Design: Make the layout adjust to different screen sizes using tools such as media queries, Flexbox, and Grid.
  • Performance: Optimize images, reduce unnecessary code, and use caching.
  • Cross-Browser Compatibility: Check that pages work in different browsers.

The WWW notes also mention Linux web server setup using Apache or Nginx, the web root directory /var/www/html, virtual hosts, firewall rules, and SSL with Let's Encrypt and Certbot.
